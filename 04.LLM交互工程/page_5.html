CHAPTER 02

协议标准能力 — Function Calling 详解

📤 请求：定义工具列表
// 在请求中增加 tools 字段
{
  "model": "Qwen/Qwen2.5-7B",
  "messages": [
    {"role":"user",
     "content":"查一下iPhone 16的库存"}
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "check_inventory",
        "description": "查询商品库存数量",
        "parameters": {
          "type": "object",
          "properties": {
            "product_name": {
              "type": "string",
              "description": "商品名称"
            }
          },
          "required": ["product_name"]
        }
      }
    }
  ]
}
📥 响应：模型返回调用意图
// 模型不直接调用，返回调用意图
{
  "choices": [{
    "message": {
      "role": "assistant",
      "tool_calls": [{
        "type": "function",
        "function": {
          "name": "check_inventory",
          "arguments": "{\"product_name\":\"iPhone 16\"}"
        }
      }]
    }
  }]
}

// 你的代码执行后，把结果传回去
{
  "messages": [
    ...,
    {"role":"assistant", "tool_calls":[...]},
    {"role":"tool",
     "content":"{\"stock\":42}"}
  ]
}

// 模型拿到结果后，生成最终回复
// "iPhone 16目前有42件库存"
关键：模型返回的是"调用意图"（函数名+参数），不是结果。你的代码执行后把结果传回去，模型再生成最终回复。
这是第七课 Tool 的基础。tools 字段定义工具，tool_calls 返回调用意图，role=tool 传回执行结果。整个流程都是 OpenAI 协议定义的。
