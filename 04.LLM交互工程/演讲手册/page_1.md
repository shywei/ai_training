## Slide Objective
开场定调。明确本课的定位：不是"教你怎么聊天"，而是"教你怎么让 Java 程序和大模型交互"。

## Suggested Presentation
欢迎来到第四课。从这节课开始，我们正式进入实战环节。

前三课我们建立了认知——知道 AI 是什么、Agent 是什么。今天开始，我们要动手做东西。

这节课的主题是 LLM 交互工程。说白了就是：你的 Java 程序怎么和大模型对话。

听起来很简单——调个 API 不就行了？但实际做起来你会发现一堆问题：大模型返回的内容带废话怎么解析？流式输出怎么处理？简单问题和复杂问题怎么用不同的模型？输出不合法怎么自动重试？恶意输入怎么防御？

这些问题，就是这节课要解决的。

## Key Emphasis
点出本课定位：工程实践，不是概念科普。从这节课开始，每一页都对应 Demo 里的实际代码。

## Take Away
从这节课开始，我们不只是理解 AI，而是用 Java 构建 AI 应用。

## Transition
要和大模型交互，首先得知道一次调用到底发生了什么。
