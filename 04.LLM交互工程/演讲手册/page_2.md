## Slide Objective
展示课程全景，让学员知道今天学什么、每部分对应 Demo 的哪里。

## Suggested Presentation
今天的课程分八个部分。

从 LLM 的运行机制开始，搞清楚一次调用到底经过了哪些步骤。然后深入 OpenAI 接口协议——这是所有大模型交互的底层标准。

接着讲 Token 和模型选型，这是成本控制的基础。然后是模型路由和结构化输出，这两个是 Demo 里的核心组件。

Prompt 工程部分涵盖结构设计、调试和安全容错。之后我们看 Spring AI 在 Demo 里到底做了什么。

最后是前端集成和完整的项目架构。

每讲完一个概念，我会展示 Demo 里对应的代码。这样你能看到"原理"和"实现"的对应关系。

## Key Emphasis
强调"每章配合 Demo 代码"——不是纯理论，是看得到、跑得通的。

## Take Away
今天的目标：看完 Demo 代码，你能理解每一行为什么这么写。
