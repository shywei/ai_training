## Slide Objective
展示课程全景导航，让学员明确今天的学习路径、每个知识模块对应 Demo 的落地点，以及核心技术架构的升级点（协议/网关双轨演进、五维路由矩阵、Guardrails 四层纵深防御、SSE 四大工程挑战）。

## Suggested Presentation
带学员浏览 7 个章节的主线：
- **01 LLM Runtime（第3页）：** 从一次 HTTP POST 调用剖析 LLM 作为 CPU 的运行链路；
- **02 OpenAI 接口协议与双轨演进（第4-6页）：** 解耦供应商 API 协议演进与企业网关架构演进，明晰兼容基线与方言适配；
- **03 Token、Prefix Caching 与模型选型（第7页）：** 算清成本账，理解前缀缓存命中与快慢模型权衡；
- **04 多维模型路由矩阵与结构化输出（第8-9页）：** 掌握成本、延迟、能力、窗口、可用性五维决策矩阵与 JSON 结构化三方案；
- **05 Prompt 工程与 Guardrails 纵深防御（第10-11页）：** 建立前缀缓存友好布局铁律，搭建从 L1 规则粗筛到 L4 事实校验的立体安全护栏；
- **06 Spring AI 封装与 SSE 四大工程挑战（第12-13页）：** 剖析框架封装机制，攻克流式传输在反向代理缓冲、数据粘包拆包、客户端断连取消与保活重连上的工程痛点；
- **07 项目架构、验证路线与生产差距（第14-17页）：** 贯通端到端源码，明晰七项生产差距与平台化归宿。

## Key Emphasis
强调课程不仅有单机 Demo 的基础实现，更有直面企业生产级架构的高维视野。

## Take Away
从协议调用到网关治理，从基础流式到生产容灾，建立立体的企业级 LLM 交互工程体系。
