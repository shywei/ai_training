├── agent-runtime/           后端 (Spring Boot)
│   ├── pom.xml              Maven 依赖
│   ├── mvnw                 Maven Wrapper
│   └── src/main/
│       ├── java/.../core/
│       │   ├── AgentApplication.java
│       │   ├── CorsConfig.java
│       │   ├── ModelRouter.java
│       │   ├── PromptManager.java
│       │   ├── StructuredOutputHandler.java
│       │   ├── GuardrailsService.java

🔑 核心文件职责
ModelRouter.java
模型路由 — 根据消息复杂度选择快模型或推理模型
PromptManager.java
Prompt 构建 — System/User 分离，模板变量替换
StructuredOutputHandler.java
结构化输出 — JSON 提取、Schema 验证、Self-Correction
GuardrailsService.java
安全防护 — 入口 Injection 检测 + 出口敏感信息过滤
ShoppingAgentController.java
导购 Agent API — 流式对话 + 结构化推荐，串联所有组件
CorsConfig.java
CORS 配置 — 前后端分离时允许跨域
application.yml
配置文件 — API Key、模型名、Agent 角色定义
v1.0-prompt — 第四课完成。后续每课都会在这个基础上增加新模块（Memory → Knowledge → Tool → Workflow）。
