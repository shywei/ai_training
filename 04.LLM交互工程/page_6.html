CHAPTER 03

Token、Context Window 与模型选型

什么是 Token？
大模型不直接处理文字，把文本拆成 token（词元）。

中文："你好世界" → [你, 好, 世界] = 3 token
英文："Hello World" = 2 token
代码：一个函数约 50-200 token

计费单位。输出 token 比输入贵 2-5 倍。
什么是 Context Window？
模型一次能处理的最大 token 数。输入+输出不能超限。

GPT-2：1K token → 约500字
GPT-4：128K → 约6万字
2026主流：100万+ → 约50万字

窗口越大，推理越慢、成本越高。
推理模型为什么贵？
推理模型回答前会生成大量思维链，这些思考过程也消耗 token。

同样一个问题，推理模型可能消耗 3-10 倍的 token。

这就是为什么需要模型路由 — 简单问题不要用推理模型。
⚡ Fast Model
日常对话、简单问答、代码补全 → 快、便宜、够用 → Qwen2.5-7B
🧠 Reasoning Model
复杂推理、架构设计、多步分析 → 慢、贵、强 → Qwen3-8B
