🧠 LLM 是 Agent 的 CPU
所有 Agent 能力（Memory、Knowledge、Tool、Workflow）最终都要通过 LLM 推理来驱动。理解 LLM 的运行机制，是一切的基础。
⚡ 推理是瓶颈
Token 编码/解码很快（毫秒级），但模型推理是 GPU 密集运算，可能需要数百毫秒到数秒。Streaming 的意义就在于不用等全部生成完再返回。
🔌 本质是 HTTP
LLM 调用本质上就是一个 HTTP POST 请求。框架封装了细节，但底层协议决定了为什么配个 URL 和 Key 就能工作。
