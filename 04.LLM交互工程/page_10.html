PromptManager.java — 构建 Prompt
@Component
public class PromptManager {

  public String buildSystemPrompt() {
    return String.format("""
      # 角色
      你是%s。%s
      # 约束
      %s
      # 输出要求
      - 回答简洁明了
      - 不确定的不要编造
      """, agentName, agentRole,
         agentConstraints);
  }

  public String buildUserPrompt(
      String msg, String context) {
    if (context == null) return msg;
    return "## 参考信息\n"
      + context + "\n## 用户问题\n" + msg;
  }
}
System/User 分离，Text Block 做模板。
context 参数当前传 null — 第四课只做系统提示词 + 用户输入。

GuardrailsService.java — 两道防线
@Component
public class GuardrailsService {

  // 第一道防线：入口检查
  public boolean checkInjection(String input) {
    for (Pattern p : INJECTION_PATTERNS)
      if (p.matcher(input).find())
        return true;  // 检测到注入
    return false;
  }

  // 第二道防线：出口过滤
  public String sanitize(String output) {
    String result = output;
    for (String kw : SENSITIVE_KEYWORDS)
      result = result.replaceAll(
        "(?i)" + kw, "***");
    return result;
  }
}
两道防线独立。入口在 Controller 开头调用，出口在返回前调用。不合并。
