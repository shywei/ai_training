CHAPTER 05 · 安全与规范

Prompt 工程与 Guardrails 纵深防御架构

📐 Prompt 结构化设计与缓存友好铁律
System Prompt（静态置顶）
定义角色、能力、红线边界与输出规范。决定 Agent 行为基线。类比员工“入职安全手册”。
User Prompt（动态置底）
动态检索上下文（用户画像、历史对话、RAG 知识片段）+ 当前用户输入。严格隔离注入。
Few-shot 少量样本示范
给小模型 1~3 个标准示范以固化格式；对深度思考推理模型则尽量减少僵化干扰。
💰 缓存友好型布局铁律
静态前缀严格置顶（System + Tools），动态变量完全置底。严禁在 System 头部塞实时秒级时间戳，否则前缀缓存命中率瞬间归零！
🛡️ Guardrails 四层纵深防御体系 (Defense-in-Depth)
⚠️ 严正警示：Regex 正则仅是最外层轻量粗筛，绝不是防注入的银弹！
L1 · 静态规则与正则层
手段：正则匹配、敏感词典、SQL/Shell 注入特征、长度截断。
特点：耗时 <1ms，零模型开销。
局限：易被同音字、藏头隐喻、多语言混淆绕过。
★ Demo 已覆盖（GuardrailsService）
L2 · 向量与分类模型层
手段：攻击向量库比对（计算与已知越狱 Jailbreak Prompt 相似度）+ 轻量小分类模型（DistilBERT）。
特点：耗时 ~5-15ms，阻断大部分变种攻击。
定位：拦截已知恶意意图的高性价比防线。
L3 · 语义审查护栏层
手段：专业安全防护大模型（Llama Guard / NeMo Guardrails），分析上下文真实意图。
特点：耗时 100-300ms，深度理解语境。
定位：防御社工伪装、催眠诱导等高阶 Prompt 注入攻击。
L4 · 输出校验与事实审查
手段：PII 脱敏脱出、幻觉与事实一致性审查（Faithfulness）、防止 Prompt 反向泄露、JSON Schema 强校验。
特点：把好最终出口关。
定位：合规兜底（Demo 已做基础敏感词替换与重试自纠错）。
生产共识：安全是层层衰减的漏斗——L1 挡粗暴攻击，L2/L3 识语义变种，L4 防幻觉合规泄露。单凭正则连 OWASP Top 10 的第 1 关都过不去。
