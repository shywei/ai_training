Demo 代码落地：PromptManager 与 GuardrailsService

PromptManager.java — 结构化 Prompt 构建
@Component
public class PromptManager {

  // 1. 静态置顶：System Prompt (角色与行为准则)
  public String buildSystemPrompt() {
    return String.format("""
      # 角色定义
      你是%s。%s
      # 严格约束
      %s
      # 输出规范
      - 仅根据参考信息回答，禁止编造事实
      - 遇到不确定的内容如实说明
      """, agentName, agentRole, agentConstraints);
  }

  // 2. 动态置底：User Prompt (上下文隔离与当前消息)
  public String buildUserPrompt(String msg, String context) {
    if (context == null || context.isBlank()) return msg;
    return "## 参考信息\n" + context + "\n\n## 用户问题\n" + msg;
  }
}
context 扩展点预留：当前第四课传 null；后续第五课注入对话历史/画像，第六课注入 RAG 检索结果，第七课注入工具执行状态。
GuardrailsService.java — 入口与出口双防线
@Component
public class GuardrailsService {

  // 第一道防线：入口检测（L1 静态正则粗筛）
  public boolean checkInjection(String input) {
    for (Pattern p : INJECTION_PATTERNS) {
      if (p.matcher(input).find()) {
        log.warn("拦截到潜在 Prompt 注入: {}", input);
        return true;  // 触发阻断
      }
    }
    return false;
  }

  // 第二道防线：出口过滤（L4 敏感信息掩码）
  public String sanitize(String output) {
    String result = output;
    for (String kw : SENSITIVE_KEYWORDS) {
      result = result.replaceAll("(?i)" + kw, "***");
    }
    return result;
  }
}
教学与生产映射：Demo 落地 L1 正则与 L4 敏感词过滤。生产级系统组合挂载 L2 向量相似度初筛与 L3 专用分类模型（Llama Guard）。注意：向量相似度仅为已知越狱库的辅助筛查，绝不能单独承担安全审查责任！
落地原则：入口防御保证“不被用户带偏”，出口校验保证“不对外说错话”，两者在 Controller 中前后呼应，绝不合并。
