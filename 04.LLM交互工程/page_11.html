CHAPTER 08 · SPRING AI

Spring AI 在 Demo 中做了什么？

Spring AI 是 Java 生态的 LLM 调用框架。它封装了底层细节，让开发者用 Java 方式调用大模型。
🔌 自动配置连接
读取 application.yml 中的 base-url 和 api-key，自动创建 HTTP 连接。
开发者不需要写任何 HTTP 请求代码。
📡 SSE 流式解析
调用 .stream().content() 时，Spring AI 自动处理 SSE 协议：
解析 data: 前缀、处理 [DONE] 标记、拼接 delta.content。
开发者拿到的是 Flux<String>，逐 token 的文本流。
🔄 非流式调用
调用 .call().content() 时，等全部生成完返回完整字符串。
用于 Self-Correction 等需要完整响应的场景。
🎯 动态模型切换
通过 OpenAiChatOptions.builder().withModel() 运行时切换模型。
这就是 ModelRouter 能工作的底层机制。
💻 ShoppingAgentController 中的 Spring AI 调用
// 流式调用（对话接口）
return ChatClient.create(chatModel)
    .prompt()
    .system(systemPrompt)      // System Prompt
    .user(userPrompt)          // User Prompt
    .options(OpenAiChatOptions
        .builder()
        .withModel(model)      // 动态模型
        .build())
    .stream()                  // SSE 流式
    .content();                // Flux<String>

// 非流式调用（结构化推荐）
return ChatClient.create(chatModel)
    .prompt()
    .system(systemPrompt)
    .user(userPrompt)
    .options(OpenAiChatOptions
        .builder()
        .withModel(model)
        .withTemperature(0.2)  // 低温度
        .build())
    .call()                    // 等待完整响应
    .content();                // String
Spring AI 做了什么：HTTP 请求构建、JSON 序列化、SSE 解析、Token 计数、错误处理。
开发者做什么：写 Prompt、选模型、处理响应。

一句话：Spring AI 把第四章讲的 OpenAI 协议全部封装了，开发者只需要关注业务逻辑。
