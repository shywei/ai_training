📦 Spring AI 封装了什么？
Prompt 组装
.system() + .user() → 组装 messages 数组
HTTP 请求
自动构建 POST 请求，加 Authorization Header
SSE 解析
.stream() → 解析 data: 行，处理 [DONE]，拼接 delta.content
模型切换
.options(withModel()) → 修改请求中的 model 字段
连接管理
读取 application.yml 的 base-url 和 api-key，自动创建连接
💻 你写的 vs Spring AI 做的
// 你写的（3行）
return ChatClient.create(chatModel)
    .prompt()
    .system(systemPrompt)
    .user(userPrompt)
    .options(OpenAiChatOptions.builder()
        .withModel(model).build())
    .stream()
    .content();

// Spring AI 内部做的（伪代码）
String json = "{\"model\":\"" + model
  + "\",\"messages\":["
  + "{\"role\":\"system\",\"content\":\""
  + escape(systemPrompt) + "\"},"
  + "{\"role\":\"user\",\"content\":\""
  + escape(userPrompt) + "\"}],"
  + "\"stream\":true}";

HttpRequest request = HttpRequest.newBuilder()
  .uri(URI.create(baseUrl + "/v1/chat/completions"))
  .header("Authorization", "Bearer " + apiKey)
  .header("Content-Type", "application/json")
  .POST(BodyPublishers.ofString(json))
  .build();

// 然后用 SSE 客户端逐行读取响应
// 解析 data: 行，提取 delta.content
// 处理 [DONE] 标记
// 返回 Flux<String>
Spring AI 不是魔法。它做的就是把你写的3行 Java 代码翻译成底层的 HTTP 请求 + JSON 序列化 + SSE 解析。理解这个链路，遇到问题时你知道去哪里排查。
