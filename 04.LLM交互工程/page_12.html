🚨 SSE 拆包粘包陷阱
流式数据在网络传输中以 TCP chunk 分发。若 chunk 恰好截断了 JSON（如前一包含 data: {"choi，后一包才含 ces"...），直接 JSON.parse() 会崩溃。处理流时必须引入 buffer 缓存机制。
💻 前端 SSE 处理代码
async sendMessage() {
  const response = await fetch(
    `/api/agent/chat?message=${text}`
  );

  // 读取 SSE 流
  const reader = response.body
    .getReader();
  const decoder = new TextDecoder();

  while (true) {
    const {done, value} =
      await reader.read();
    if (done) break;

    buffer += decoder.decode(value,
      { stream: true });

    // 解析 SSE: data: xxx
    for (const line of lines) {
      if (line.startsWith('data:')) {
        const content =
          line.substring(5);
        if (content === '[DONE]')
          continue;
        fullText += content;
        // 更新 UI
        msg.content = fullText;
      }
    }
  }
}
