CHAPTER 06

Prompt 工程 — 结构、调试与安全

System Prompt
定义角色、能力、约束。用户看不到，但决定 Agent 全部行为。类比：入职培训手册。
User Prompt
用户问题 + 上下文（RAG结果、用户画像等）。类比：客户需求。
Few-shot
给模型 1-3 个示例，它会模仿格式和风格。最有效的技巧之一。
🧪 调试四件套 （仅 PPT 讲解）
Playground（快速迭代）
Logging（记录输入输出）
AB Test（对比效果）
Evaluation（量化准确率）
🛡️ 两道防线 （Demo 已覆盖）
入口：Prompt Injection 防御（正则检测、关键词拦截）
出口：敏感信息脱敏、违规内容拦截
两道防线各自独立，不合并。
🔄 Self-Correction （Demo 已覆盖）
LLM 输出非法 → Java catch 捕获 → 异常信息发回 LLM → 重新生成。
服务端重试，不是 LLM 自纠错。
⚡ Streaming 冲突 （仅 PPT 讲解）
流式输出时不能逐 chunk 检查。
方案：首个 chunk 检查 Injection，或关键接口不走 Streaming。
Prompt 是代码，不是文案。需要版本控制、测试、监控、迭代。
