ReAct 主循环接管：从 300 行手写状态循环到 ReActAgent

五步看透 ReActAgent：问题：V5/V6 都得手写 while (step < MAX) 推动 THINK-ACT-OBSERVE ➔ 概念：AgentScope ReActAgent ➔ 原理：内核内置规划-调用-观察循环与 maxIters 熔断 ➔ 调用：配置期组装模型/Toolkit/中间件，运行期一行 call() 委托执行。
1. 装配期：AgentScopeConfig.java Toolkit + ReActAgent.builder()
// 1. 构建 OpenAI 兼容模型客户端（直连 SiliconFlow） Model model = OpenAIChatModel.builder() .apiKey(apiKey).baseUrl(baseUrl).modelName(modelName).stream(true).build(); // 2. 注册带 @Tool 注解的企业导购工具集 Toolkit toolkit = new Toolkit(); toolkit.registerTool(shoppingAgentTools); // 3. 装配 ReActAgent（框架内核接管多轮 ReAct 循环） return ReActAgent.builder() .name(agentName).sysPrompt(systemPrompt) .model(model).toolkit(toolkit).maxIters(10) .middlewares(List.of(schemaRepairMiddleware, lifecycleMiddleware)) .stateStore(checkpointStore.getAgentScopeStateStore()).build();
✅ 核心差异：ChatClient 只管单次调用；ReActAgent 把“循环引擎 + 工具路由 + 中间件 + 状态存储”打包为完整运行时。
2. 运行期：AgentScopeWorkflowAdapter.java 消灭手写 while 循环
// 构建本次执行隔离上下文（绑定 sessionId 与 userId） RuntimeContext context = RuntimeContext.builder() .sessionId(execId).userId(userId).build(); // 一行代码委托 ReActAgent 推进多轮思考、调工具与收敛！ Msg responseMsg = shoppingAgent.call(message, context).block(); String answer = responseMsg != null ? responseMsg.getTextContent() : ""; // 若触发中间件风控拦截，直接返回 CONFIRMING 审批响应 if (Boolean.TRUE.equals(context.get("APPROVAL_REQUIRED"))) { return WorkflowResponse.confirming(execId, ...); }
