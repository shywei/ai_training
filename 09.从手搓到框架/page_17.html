告别“算完再拆字”的伪流式：类型化 AgentEvent 多通道事件流

五步看透多通道流：问题：V5 同步跑完再用 Flux.interval 拆字符（伪流式，首字等 5~8s）；V6 仅单通道文本流，思考与正文混杂 ➔ 概念与原理：AgentScope streamEvents() 实时发射 30+ 种强类型 AgentEvent，前端按 channel 独立渲染。
通道 1 · 思考过程流（thought）
THINKING_BLOCK_START / DELTA / END ➔ 前端折叠“深度思考中”卡片
通道 2 · 工具执行流（tool）
TOOL_CALL_START / DELTA + TOOL_RESULT_END ➔ 即时点亮“正在查库存”进度条
通道 3 · 正文回答流（answer）
TEXT_BLOCK_START / DELTA / END ➔ 纯净打字机流式输出，无需正则剥离标签
通道 4 · 审批与自愈控制流（confirm / repair）
REQUIRE_USER_CONFIRM + CUSTOM("SchemaRepair") ➔ 弹窗审批确认
延迟对比：V5 伪流式 (3~8s) ➔ V6 单文本流 (1~2s) ➔ V7 类型化事件流 (<100ms 首个进度事件)
