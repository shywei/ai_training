CHAPTER 05 · 2026 技术生态与非功能底座

生产级非功能底座：可观测性（Tracing）、六维评估（Evals）与安全防线

跑通 Demo 只完成 20%；在企业真实生产中，必须建立全链路 Tracing、六维自动化评估体系与纵深安全防护。
① 全链路 Tracing OTel 规范
当用户投诉“响应慢且答非所问”，秒级定位根因：
• 树状调用轨迹（Trace ➔ Span）
一次请求分配一个全局 TraceId，每个步骤（Memory、RAG、LLM、MCP）作为子 Span。
• 关键指标采集
记录单步耗时、Token 消耗（含缓存命中率）、完整 Prompt 快照与工具原始返回值。
• 秒级故障定界
一眼分清是 RAG 召回差、外部 MCP 接口超时还是模型选错工具。
实践：TraceService + 调用链时间轴
② 六维自动化评估体系（Agent Evals） 拒绝单凭直觉
评估绝不仅是“回答文字好不好看”！必须覆盖智能体运行全生命周期的六大正交维度：
1. 模型输出质量 (Output Quality)
事实忠实度（Faithfulness）、答案相关度、幻觉发生率与指令格式遵循度。
2. 工具调用准确率 (Tool Accuracy)
工具名称选择正确率、参数 Schema 符合率、参数完整提取率与无多余无用调用。
3. 任务最终完成率 (Task Success)
端到端业务目标达成率（Pass@k）、交付工件（Artifact/订单/代码）正确可用性。
4. Workflow 执行可靠性 (Workflow Reliability)
状态机合法迁移率、重试与异常自愈成功率、规避无意义死循环步骤效率。
5. 安全与权限违规率 (Safety & Policy)
越权工具调用发生率、提示词注入（Prompt Injection）拦截率、敏感 PII 泄露率。
6. 成本与响应延迟 (Cost & Latency)
首字延迟（TTFT）、端到端 P95 响应耗时、平均任务 Token 吞吐开销与缓存命中率。
工程铁律：建立黄金评测基准集（Golden Benchmark），改 Prompt 必须全量回归！
③ 纵深安全防线 防御提权
Agent 拥有 API 调用权，一旦被利用危害极大：
1. 防御间接注入 (Indirect Injection)
不仅用户输入不可信，外部检索网页也可能含带毒指令。用 XML 标签严格物理隔离数据区。
2. 敏感数据双向脱敏
发往大模型前，敏感手机号、身份证由 GuardrailsService 自动掩码，返回前再次反脱敏。
3. 最小权限 + 人工审批 (HITL)
高危接口调用必须暂停并弹窗触发人工审批确认。
防线：输入过滤 + 输出审计 + 沙箱兜底
架构师非功能军规： 传统软件测接口可用性，Agent 系统测六维综合得分。没有自动化评测集和全链路可观测性，任何对 Prompt 和 Workflow 的重构都是蒙眼狂奔！
