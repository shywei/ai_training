## Suggested Presentation
各位架构师与同仁，恭喜大家完成了第三课《AI Agent 架构认知入门》的深度修炼！
让我们站在全景高度，收束今天的【六大核心架构心智】：
1. **架构第一分水岭**：确定性编排（Workflows）管边界与交易，模型自主循环（Agents）管意图与推演；
2. **灵魂中枢**：Context Engineering 动态组装是决定 Agent 性能与智商的第一管道工程；
3. **架构核心公式**：Enterprise Agent = Model + Memory + RAG + Tool + Workflow，五位一体；
4. **能力成熟度阶梯**：从交互基础、记忆机制、知识增强、系统集成到确定运行，五阶层层递进；
5. **七层技术坐标**：看懂生态坐标图，善用五问决策树按需裁剪，拒绝盲从与技术焦虑；
6. **工程底座**：没有 Tracing、Evals 与安全防线的 Agent 只是玩具，务实遵循 MVP 渐进演进！

**智能体系统工程演进全貌：**
本课作为认知总纲，我们通过电商导购等工业案例全面建立了全局架构大局观。在后续的技术演进中，企业级智能体系统将沿着五大核心能力纵深推进：
- **模型交互与契约**：构建高低模型路由分流与强类型输出自愈机制；
- **多层记忆系统**：攻克短期窗口、结构化画像与长期语义记忆的双通路流转；
- **知识检索与增强**：打造半结构化条目与非结构化长文档的生产级 RAG 闭环；
- **工具连接与协议**：通过 MCP 协议实现领域服务解耦与标准治理；
- **状态机编排治理**：用受控有限状态机与人在回路机制筑牢工业级 SLA！
再次牢记全课核心：Agent 不是模型，Agent 是围绕模型构建的完整软件系统！

## 课后扩展学习引导（Post-Class Deep Dive Guide）
各位架构师同仁，在完成第三课的认知筑基后，如果您正在规划或评审团队内部的企业级智能体立项方案，强烈建议大家精读本课根目录下的**《扩展学习指南.md》**！

这份指南遵循 3W 原则（Why-Where-What），从工业落地视角剖析了四大深水区主题：
1. **智能体设计范式去泡沫（Workflow vs Autonomous Agent）**：深度解读 Anthropic《Building Effective Agents》与 Lilian Weng 奠基长文，清晰划分 5 种高可靠工作流模式与开放式 Agent 的适用边界；
2. **四大推演规划范式横向对比**：精选 ReAct（`arXiv:2210.03629`）、Reflexion（`arXiv:2303.11366`）、Plan-and-Solve 与经典 GOAP 论文，从延迟、成本、容错与状态机控制等维度为选型提供标尺；
3. **2026 智能体三大正交协议体系**：全景图解 MCP（模型调工具）、Google A2A（智能体间对等协作）与 AG-UI（前端流式生成界面）的系统拓扑与职责分界，杜绝点对点网状集成的技术负债；
4. **企业级 Trajectory 评估体系**：告别“试两把全凭感觉”的业余做法，解析 Anthropic 轨迹评估方法学，如何以最小代价搭建覆盖核心业务路径的自动化评测回归套件。

指南文末特别准备了 3 道直击高频事故的架构辨析题（理赔业务边界决策、推演死循环熔断、跨 Agent 协议隔离），是检验团队是否真正具备系统架构定力的绝佳试金石！
