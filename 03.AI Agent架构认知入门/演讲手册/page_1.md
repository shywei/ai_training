作为全套智能体课程的理论与架构总纲封面，明确从“单次模型调用”跃迁到“企业级生产智能体系统”的核心定位，建立严谨的架构师视角。

## Suggested Presentation
各位技术架构师、骨干开发工程师，大家好！欢迎来到第三课：《AI Agent 架构认知入门：从单次调用到企业级智能体系统》。
在前面两课中，我们已经打通了大模型底层工作机制，并掌握了如何用 AI 辅助我们日常写代码。
从今天开始，我们的角色将发生重大转变——我们不再只是 AI 的使用者，我们要成为**“企业级 AI Agent 系统的架构设计者与缔造者”**！
很多团队把调用一次 OpenAI API 得到一段回复就称为“智能体”，这在架构上是完全不合格的玩具。
今天这节课，是统领智能体技术体系的“架构总纲与认知基座”。
我们将拆解 Workflows 与 Autonomous Agents 的分水岭；剖析 ReAct、Plan-and-Execute 等三大认知循环；给出智能体系统运行时中枢——Context Engineering（上下文工程动态组装全景图）；并以经典智能导购等业务场景举例，拆解通用的企业级智能体工业参考架构全景！
让我们带着构建企业级高可靠系统的决心，正式开启架构之旅！

## Key Q&A / Clarifications
**Q：第三课在整个课程体系中的生态坐标是什么？**
A：第 03 课是智能体系统的架构师宏观视角。本课不涉及具体 Demo 代码实操演练，而是纯粹从架构原理与工业参考模型出发，用通用业务案例（如智能导购、智能企业助手）举例，系统拆解模型路由、三层记忆、知识检索、工具协议与状态机治理，帮助大家建立起严谨的全局系统设计认知。
