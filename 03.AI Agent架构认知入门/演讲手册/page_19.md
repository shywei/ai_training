## Suggested Presentation
请看第 19 页：Agent 基础认知误区辨析（五问五答）。
我们逐一打破市场上最常见的五个“智能体幻觉”：
1. **误区一：“Agent 必须完全自主，人类干预越少越高级？”**
   —— **彻底错误！** 企业生产要的是 100% 的业务确定性，而不是不可控的自由。优秀的企业架构追求“确定性受控自主（Controlled Autonomy）”，关键节点必须有人类在回路（Human-in-the-loop）；
2. **误区二：“大模型上下文窗口已经 200 万了，Agent 还需要复杂的 Memory 架构吗？”**
   —— **必须需要！** 窗口容量不等于注意力召回精度。长上下文不仅昂贵、慢，更会导致严重的 Lost in the Middle。三层冷热记忆是控制成本和保持精度的必然路径；
3. **误区三：“Multi-Agent 比单 Agent 永远更强？”**
   —— **警惕陷阱！** Multi-Agent 带来了巨大的通信开销、延迟翻倍和死锁风险。如果单 Agent 配好 Tools 就能搞定，绝不上多智能体；
4. **误区四：“Agent 会彻底取代传统后端微服务？”**
   —— **不会！** Agent 是微服务的编排者和智能门户，底层的数据一致性、高可用存储、事务控制仍然依赖传统微服务；
5. **误区五：“Prompt 越长、写得越详细，Agent 就越聪明？”**
   —— **过犹不及！** 过度冗长的 Prompt 会严重稀释注意力，引发规则互斥冲突。规范必须精炼、模块化，善用 Hooks 代替文字。
