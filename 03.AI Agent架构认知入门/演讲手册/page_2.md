## Suggested Presentation
请看全课目录。今天的架构大纲由六大章节层层推进：
第一章【概念分野与范式分水岭】：讲透为什么裸模型不够，剖析 Anthropic 经典分水岭（Workflows 确定性编排 vs Autonomous Agents 自主智能体）以及通用 Harness vs 垂直 Agent 的形态分野；
第二章【运行时认知循环与动态上下文组装】：剖析 ReAct、规划执行与反思三大认知循环，揭秘智能体系统的核心中枢——Context Engineering 动态组装解剖图；
第三章【企业级 Agent 核心组件精讲】：系统拆解认知层（Prompt/模型路由/结构化输出、三层 Memory、双形态 RAG）与执行层（Tool/MCP、状态机 Workflow）；
第四章【架构总蓝图：工业参考模型与能力分级】：以通用智能导购业务为例，拆解企业级智能体分层架构全景图、八步端到端交互时序与智能体工程能力五级成熟度阶梯；
第五章【2026 技术栈坐标与架构师决策树】：给出 7 层生态坐标图与业务需求五问决策树，彻底解决“新工具往哪放、业务来怎么选”的困惑；
第六章【非功能底座与落地反思】：剖析可观测性 Tracing、自动化评测 Evals、安全防线与反过度设计 MVP 演进原则。

## Key Q&A / Clarifications
**Q：第三课会讲具体框架（如 LangChain、LangGraph）的用法吗？**
A：本课聚焦在**框架之上的系统架构本质**。无论你未来用 LangGraph、Spring AI 还是自己手写原生 Agent，底层的认知循环、Context 组装与状态机逻辑是 100% 通用的。具体框架对比与深入选型将在后续专题展开。
