CHAPTER 05 · 2026 技术生态与架构决策树

2026 AI Agent 七层技术栈生态坐标（新工具冒出来往哪一层放？）

消除技术焦虑的最好办法是建立分层坐标系——看清每一层解决什么问题，明确哪些是我们应用架构师的主战场：
L7 · 产品与应用层
通用 Harness vs 垂直 Agent
Claude Code / Qoder / OpenClaw (通用 Harness)
Dify / Coze / FastGPT (低代码工作流平台)
★ 企业自研垂直 Agent (如电商导购/企业助手)
L6 · 开放互操作协议层
2026 三大通信标准
★ MCP (Model Context Protocol：模型接工具/数据标准)
★ A2A (Agent-to-Agent：跨智能体协作标准)
★ AG-UI (Agent-User Interaction：前端流式事件标准)
L5 · 编排与运行时层
状态机 · 循环 · HITL · 记忆
★ 自研轻量 FSM 状态机 (受控 AgentRuntime)
★ AgentScope Java 2.0 (生产级多智能体运行时)
LangGraph / Spring AI Alibaba Graph
L4 · AI 开发框架/SDK层
统一模型/向量库/MCP抽象
★ Spring AI 1.x / 2.0 (Java 企业开发首选主力)
LangChain4j (Java 备选)
LangChain / LlamaIndex (Python 生态)
Vercel AI SDK / Mastra (TS)
L3 · 网关与治理底座层
路由 · 限流 · Tracing · Evals
Higress / LiteLLM / OneAPI (AI & MCP 网关)
OpenTelemetry / Langfuse / Arize Phoenix (可观测追踪)
RAGAS / DeepEval (自动化评测)
L2 · 基础与专用模型层
推理 · 快模型 · 向量 · 重排
旗舰推理：DeepSeek-R1/V3 · Qwen3-Max · Claude 4 · GPT-5
快模型：Qwen-Turbo / 4o-mini
Embedding & Reranker (BGE / text-embedding-v3)
L1 · 存储与算力底座层
状态存储 · 向量检索引擎 · 推理集群
★ PostgreSQL + pgvector (向量+关系一体化)
★ Redis (短期记忆缓冲) + MySQL (核心业务表)
vLLM / SGLang / Milvus / ES
🎯 架构师与后端工程师主战场（L3 ~ L6）：精通 Spring AI + AgentScope 2.0 + MCP/A2A + pgvector + 状态机治理，即可搞定 95% 企业级 Agent 系统。
💡 为什么架构设计中优选 PostgreSQL `pgvector` 而非独立 Milvus？中小规模（千万级向量以内）用 pgvector 可实现向量与业务字段同库过滤、零额外运维负担！
