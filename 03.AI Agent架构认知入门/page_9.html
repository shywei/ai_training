CHAPTER 04

Tool与MCP：原理与实现

是什么？
Tool给Agent"手"——让它能调用外部系统。
MCP是Tool的标准化协议——统一工具接口。
两者关系：Tool是能力，MCP是标准。
解决什么问题？
LLM不能操作外部系统——不能调API、查数据库。
没有MCP，每个工具单独适配，换框架全部重写。
MCP统一标准：一次开发，处处可用。
和其他能力的边界
Tool调API（实时数据），Knowledge查文档（静态知识）。
Tool返回的是结构化数据（库存数量、订单状态）。
Knowledge返回的是文本段落（产品说明、政策内容）。
MCP是Tool的协议层，不是独立组件。
系统组成
Tool系统 = Function Definition（函数+描述）+ MCP Server（封装暴露）+ MCP Client（发现调用）+ LLM（Function Calling）
SDK: MCP Python/TS · Spring AI @Tool  |  Client: Claude Code / Cursor / Claude Desktop
