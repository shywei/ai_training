CHAPTER 04 · 架构总蓝图：企业级智能体系统参考模型（分层架构全景）

架构总蓝图（上）：企业级智能体系统工业参考架构全景

以经典智能导购与企业助理为例，构建现代化多模块生产级智能体工程拓扑与工业级分层架构：
前端交互层 现代化 Web / 移动交互终端 SSE 流式打字机响应 · 实时执行步骤状态栏 · HITL 高危下单确认卡片 · Trace 调试面板
POST /api/chat/stream & /api/chat/confirm ⬇
核心智能体引擎宿主 (Agent Runtime) 智能体运行时引擎（控制流驱动 + 上下文组装中心）
对外暴露 REST / SSE · 对内调度 LLM / Memory / MCP
1. GuardrailsService · 安全护栏
输入敏感词/Prompt注入拦截、手机号/身份证 PII 脱敏
2. PromptManager · 提示词管理
管理 System 角色模板、缓存友好型前缀与 JSON 输出约束
3. MemoryManager · 记忆编排
统一编排近期会话窗口、用户画像与语义记忆
4. LlmRouter · 模型路由
按意图复杂度动态路由 Fast 快模型与 Reasoning 旗舰模型
5. Runtime & TaskPlanner · 状态引擎
FSM 有限状态机驱动（PLANNING → EXECUTING），控制最大步数
6. ConfirmationService · 审批拦截
拦截高危工具（如创建订单），保存待确认快照，等待人工审批
7. ErrorRecovery · 韧性容错
JSON 自愈重试 + 工具调用指数退避重试 + 熔断降级兜底
8. TraceService · 全链路追踪
全链路记录每个 Step 的耗时、Token 消耗、工具入参出参与状态
领域工具微服务 (Domain Tool Server) · 商品与交易 MCP HTTP/SSE
暴露核心交易 Tools：search_products（条件筛选商品）、get_product_detail（查实时价格与库存）、calculate_discount（满减核算）、create_order（高危写操作·需HITL确认）。
知识检索微服务 (Knowledge Retrieval Server) · 知识与记忆 MCP HTTP/SSE
暴露认知检索 Tools：search_knowledge（混合检索商品深度评测/尺码指南/退换货规则 + Rerank）、get_user_profile & recall_user_memory（读写画像与长期记忆）。
Redis 内存缓存
短期对话滑动窗口 + 会话摘要 + HITL 待确认挂起快照
MySQL 关系型数据库
product 实时价格库存表 + user_profile 结构化用户画像表
PostgreSQL + pgvector 向量库
knowledge_vector 私域知识向量表 + user_memory 长期语义记忆表
