+ Tool + Workflow

→ 用什么技术 → 怎么集成
不要从技术出发，要从问题出发

→ Memory
需要查文档？
→ Knowledge (RAG)
需要调系统？
→ Tool + MCP

→ Workflow
需要专业分工？
→ Multi-Agent
