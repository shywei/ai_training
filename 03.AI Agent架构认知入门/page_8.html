CHAPTER 04

Knowledge与RAG：原理与实现

是什么？
让Agent能"查资料"——接入企业知识库、文档、产品信息。
Knowledge是"事"的信息——知道这家公司。
核心技术是RAG（检索增强生成）。
解决什么问题？
LLM的训练数据是冻结的——不知道企业内部文档。
Context Window有限——塞不下全部知识。
RAG按需检索：只把最相关的几段塞进Context。
从"LLM什么都知道"变成"LLM能查资料"。
和其他能力的边界
Knowledge记"事"，Memory记"人"。
Knowledge查的是文档库，RAG流程自动检索。
Tool调的是API，返回实时数据。
Knowledge=查文档，Tool=调系统。
系统组成
RAG = Embedding Model + Vector DB + Retriever + Reranker（可选）+ LLM
Embedding: OpenAI ada / BGE / Jina  |  Vector DB: Milvus / PgVector / Chroma  |  框架: Spring AI RAG / LlamaIndex
