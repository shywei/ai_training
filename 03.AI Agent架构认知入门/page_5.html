CHAPTER 03

Agent能力全景图

一个完整的Agent系统，由两类能力组成：
🧠 认知层——Agent"知道什么"
Prompt
定义Agent如何工作——角色、能力、约束
Memory
记住用户——对话历史、偏好、上下文
Knowledge
理解企业知识——RAG检索文档、产品信息
⚡ 执行层——Agent"做什么"
Tool
操作外部系统——调API、查数据库
MCP
标准化工具协议——统一接口、跨框架复用
Workflow
编排复杂流程——多步骤、条件、人工审批
Multi-Agent
多Agent协作——分工、协调、团队完成任务
Prompt + Memory + Knowledge = 认知（知道什么）
Tool + MCP + Workflow + Multi-Agent = 执行（做什么）
LLM是大脑，连接认知和执行。不是每个Agent都需要全部能力——按需组合。
