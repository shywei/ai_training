CHAPTER 01 · 范式边界：AGENT 核心定义与产品形态

核心定义与形态分水岭：通用 Harness vs 垂直应用 Agent

【P0 核心定义】：什么是真正的 AI Agent？ 彻底破除概念矛盾
Agent 是以大模型为认知与决策引擎，通过上下文、记忆、工具和运行时控制机制构成的智能应用系统。系统需要用确定性工程机制约束模型的不确定性。
纠偏：大模型本身是连续条件概率流形采样，绝非确定性 CPU！试图将模型称为“确定性 CPU”自相矛盾。真正的工程思想是：模型负责发散与认知推理，外围的上下文装配、分层记忆、工具沙箱与状态机运行时负责收敛确定性边界。
核心维度
通用智能体宿主（General Agent Harness）
企业垂直应用 Agent（Vertical Domain Agent）
代表产品与受众
Claude Code、OpenClaw、Cursor（面向开发者）
电商智能导购、智能理赔、ERP 助手（面向企业业务客户）
能力边界配置权
终端用户开放自配：用户挂载本地 Shell、私有 MCP 与自定义 Rules
研发团队严格封闭：System Prompt、业务可用 MCP 工具与权限死锁
发力方向比喻
横向广度（改装越野车）：文件读写 + Bash 即可干万物，重在长上下文沙箱
纵向深度（工业专用机床）：深耕单一业务域，重在私域数据、一致性与合规
核心研发重心
插件生态、本地权限审批、长会话 Compaction、多模型路由
领域 Prompt、分层业务 Memory、私域 RAG、内部系统 MCP、状态机护栏
LAYER 1 · 编排工具与零件
开发框架 / SDK
Spring AI 2.0、AgentScope、LangGraph：提供 ChatClient、VectorStore 与状态图抽象，供程序员编写系统。
LAYER 2 · 开放式通用越野车
通用 Agent Harness
Claude Code、Qoder、OpenClaw：面向开发者的开箱即用研发宿主，直接使用，不要在企业业务中重复造轮子。
LAYER 3 · 深度定制专用机床
企业垂直应用 Agent
企业导购/理赔系统（我们亲手造的业务系统）：严禁开放通用 Shell！用确定性工程机制精细编排，安全交付业务价值。
