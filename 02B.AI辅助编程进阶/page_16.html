CHAPTER 04 · 团队级 CONTEXT 治理与工程免疫飞轮

团队工程免疫飞轮（Compound Engineering 复利工程）

什么是复利工程（Compound Engineering）？ 平庸团队每次踩坑都是个体口头抱怨；优秀团队把每次 AI 翻车沉淀为全员共享的规则疫苗（Rule / Hook / Skill），让全团队永久免疫，越用越聪明！
1. 故障发生 (Incident)
捕获 AI 典型恶习
例如：AI 在重构时把手机号脱敏漏掉了末位校验，导致线上报文泄露。
// 事故记录:
Bug #1042: 手机号掩码脱敏误伤 18 位身份证。
2. 根因复盘 (Post-Mortem)
提炼反模式特征
发现根本原因：正则未加前后非数字边界断言，导致长数字串被部分截断。
// 根因特征:
缺失 (?<!\\d) 与 (?!\\d) 边界约束。
3. 规则沉淀 (Vaccine)
提交 3 行疫苗规则
随 PR 补充 3 行规则到 `.rules/pii.mdc`，并添加 1 个回归单测断言。
# .rules/pii.md:
手机号正则必须使用前后非数字断言，防止误伤快递单号。
4. 全员免疫 (Immunity)
团队资产永久生效
全团队后续任何人在开发脱敏逻辑时，Agent 自动带出该规约，永久杜绝重复踩坑！
[Immunity Achieved]
同一个坑全团队绝不踩第二次。
团队文化导向：将“为团队写一条高质量 Rule / Skill”纳入工程卓越奖励，形成工程资产复利滚雪球！
