CHAPTER 05 · GIT WORKTREE 并行与 CI/CD 无头 AGENT

高阶提效 ② · Headless Agent 融入 CI/CD 研发流水线

从“个人桌面交互工具”升级为“7×24 小时流水线数字员工”： 通过无头 CLI（如 `opencode run "..."` 或 `agy run "..."`）将智能体嵌入 GitLab CI / GitHub Actions，在自动化流水线中承担 PR 预检、单测修复与安全扫描。
流水线 1：PR 自动初审员 PR Review
在开发者提 PR 时自动触发，分析 Diff 是否违反团队 `AGENTS.md` 规约，对潜在安全漏洞直接在 GitHub/GitLab 评论区指出。
# CI Step:
opencode run "审查本 PR 的 git diff，根据根目录 AGENTS.md 输出安全建议"
流水线 2：编译红线自动自愈 Auto Fix
当 CI 编译或单测挂掉时，自动捕获报错日志并拉起无头 Agent。若在安全阈值内（如单纯 import 遗漏/类型转换），自动生成 fix 分支！
# CI Step:
opencode run "读取 maven-error.log，修复 compilation error 并重跑单测"
流水线 3：夜间自动化巡检 Cron Patrol
夜间定时扫描过时依赖版本、死代码与低覆盖率模块，自动按 SDD 格式生成 `.specs/maintenance/` 改进 PR 供工程师早晨审批。
# CI Step:
opencode run "扫描存量中圈复杂度大于15的类，生成黄金特征测试"
未来研发愿景：人类工程师聚焦需求架构与审批，无头 Agent 在流水线上打辅助，实现 7×24 小时不间断的工程质量巡航。
