# 企业全局宪法 (AGENTS.md · OpenCode 原生支持)
## 1. 快速编译与秒级单测命令
- 编译检查: `mvn test-compile -T 1C -q`
- 单个测试类: `mvn test -Dtest=PiiMaskUtilsTest`
- 单个测试方法: `mvn test -Dtest=ClassName#methodName`
## 2. 模块职责与依赖方向
- `core-service`: 通用业务逻辑与工具类
- `order-service`: 订单交易处理与库存预占
- `test-suite`: 业务回归用例与黄金断言集
## 3. 企业研发四大铁律 (Red Lines)
1. [Spec 先行] 跨方法特性必须先在 `.specs/<feat>/` 生成 EARS requirements 与 design，人工确认后再编码。
2. [防作弊红线] 编码阶段绝对禁止修改、删除或 @Disabled 任何 `src/test/` 下已锁定测试断言！
3. [异常与安全] 严禁空 catch 吞异常或返回 TODO 假桩；日志禁止打印明文手机号与密钥。
4. [依赖锁死] 未经人工审批禁止修改 pom.xml 引入外部包。
工件 2：物理防篡改 Hook (`.opencode/hooks/protect-tests.sh`) PreToolUse 拦截
#!/usr/bin/env bash
# 监听 Edit / Write 工具调用
TOOL_NAME="$1"; FILE_PATH="$2"
if [[ "$TOOL_NAME" =~ ^(Edit|Write)$ ]]; then
  # 拦截 1: 锁死测试目录，防止篡改断言
  if [[ "$LOCK_TESTS" == "1" && "$FILE_PATH" =~ src/test/.*Test\\.java ]]; then
    echo "🚨 [HOOK BLOCKED] 当前处于实现阶段，严禁篡改测试断言！" >&2
    exit 2
  fi
  # 拦截 2: 锁死 pom.xml 杜绝包幻觉
  if [[ "$FILE_PATH" =~ pom\\.xml$ ]]; then
    echo "🚨 [HOOK BLOCKED] 严禁私自修改 pom.xml 引入外部依赖！" >&2
    exit 2
  fi
fi
exit 0 # 校验通过放行
