LEVEL 1 · 问答补全者
Chat & Tab 搬运工
• 单函数补全与报错复制粘贴
• 人肉充当剪贴板与 I/O 总线
• 提效上限：15%~20%
LEVEL 2 · 凭感觉盲改者
Vibe Coder 抽卡
• 快速搭 Demo，但存量工程翻车
• 无 Spec、无单测，常被 AI 欺骗
• 风险：代码腐化、巨型 PR 审查瘫痪
LEVEL 3 · 规格驱动工程师
SDD 存量掌控者 (02B核心)
• 先审 Spec 再编码
• 黄金回归锁死祖传代码，秒级自愈
• Hook 拦截作弊，worktree 并行提效 300%+
LEVEL 4 · 复利与 Harness 架构师
团队免疫构建者
• 分层级 AGENTS.md 与按需规则治理
• 踩坑沉淀为全员共享 Rule/Skill 疫苗
• Headless Agent 融入 CI/CD 自动化
明天回到工位即可落地的《企业级 AI 研发六大黄金军规》：
1. 审 Spec 胜过审千行代码：超 3 个文件的需求必须先出 design.md，人类把关架构与复用。
2. 不锁测试不动老代码：重构祖传代码前先让 Agent 生成黄金特征测试并锁定全绿。
3. 定向单测做 AI 的眼睛：把 mvn test -Dtest=... 写入 AGENTS.md，赋予 Agent 2 秒自愈闭环。
4. 物理护栏防 Reward Hacking：用 PreToolUse Hook 锁死测试目录，杜绝 AI 篡改断言作弊。
5. 根目录 AGENTS.md 严控 150 行：格式废话交给 Linter，领域规范拆入子模块与 Glob Rules。
6. 踩坑必留疫苗（复利飞轮）：每修一个 AI 翻车的 Bug，随 PR 补充 3 行规则让团队永久免疫。
