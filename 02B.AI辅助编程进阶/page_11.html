CHAPTER 03 · AGENTIC TDD 验证闭环与防作弊纪律

构建秒级反馈的自动化验证闭环（Agentic TDD）

为什么自动化测试是 Coding Agent 的“眼睛”？ 没有编译器报错和单测断言，Agent 只是在黑盒里凭概率默写代码（一次交付率 <45%）；接入秒级验证工具链后，Agent 形成 Red(写测试) → Green(自愈修复) → Refactor 闭环，交付通过率跃升至 >92%！
第 1 道门：编译器静态检查 ~1.5 秒
拦截幻觉 API、不存在的方法签名、类型不匹配与未捕获异常。Java 强类型编译器天然是防幻觉第一道过滤器。
# 快速增量编译命令:
$ mvn test-compile -q -T 1C
// 仅输出 ERROR 行，省 90% Token
第 2 道门：方法级定向单测 ~2.0 秒 [核心]
严禁跑全量 test（耗时10分钟且冷启 Spring 极慢）！指导 Agent 仅针对修改的方法运行纯内存 Mock 单测。
# 定向单测秒级执行:
$ mvn test -Dtest=ServiceTest#shouldMaskPii
// 2秒内反馈，驱动快速自愈
第 3 道门：静态代码规范检查 ~3.0 秒
通过 Spotless / Checkstyle / ArchUnit 拦截格式不符、圈复杂度超标与跨层非法调用，保证代码整洁度。
# 格式与合规自动对齐:
$ mvn spotless:apply -q
// 消除 100% 格式争议
自愈闭环纪律：把这三条命令写入 `AGENTS.md`，Agent 每次修改代码后自动顺序触发，红灯则自主修复，直至全绿才向人类汇报！
