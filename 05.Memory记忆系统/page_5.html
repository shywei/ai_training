CHAPTER 03

Session Memory — 方案全景

方案一：内存存储
ConcurrentHashMap / Caffeine
✅ 最快，零依赖
❌ 重启丢失，不支持多实例
适用：原型开发、单机部署
方案二：Redis（主流）
List 结构，RPUSH/LRANGE
✅ 快、支持集群、自带过期
❌ 需要额外部署
适用：生产环境、多实例部署
方案三：数据库
MySQL messages 表
✅ 持久化、可查询
❌ 读写慢
适用：需要审计、合规场景
Token 爆炸问题
两种解决策略：
滑动窗口——裁掉旧消息
后台压缩——旧消息→摘要
