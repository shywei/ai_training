CHAPTER 08

生产环境注意事项

多用户隔离
每个用户的数据必须隔离。
Redis Key 带 userId 前缀。
MySQL 查询必须带 userId 条件。
绝不能让 A 看到 B 的画像。
Memory Debug
生产环境需要能看到每个用户的：
· 当前 Session 消息列表
· 用户画像内容
· context 注入了什么
· 压缩历史和摘要
性能与成本
压缩和抽取都调用 LLM，有成本。
需要监控：每次压缩消耗多少 token？
画像抽取失败率多少？
建议做成本看板。
Memory 与 RAG 配合
用户问"我上次看的那个笔记本还有货吗"
Memory 记住了"上次看了联想小新Pro"
RAG 去查库存文档。两者配合才能回答。
Memory 与 Tool 配合
用户说"按我之前的偏好下单"
Memory 提供偏好 → Tool 调用下单 API。
这就是 v4.0 的完整形态。
