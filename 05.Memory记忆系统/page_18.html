CHAPTER 09 · 业界视野

业界记忆系统一览 — 本课三层记忆的坐标系

MemGPT / Letta — LLM 当操作系统，上下文当内存
思路：把 LLM 看作 OS、上下文窗口看作内存，记忆按分页在"核心内存 / 外部存储"间换入换出（2023 论文 MemGPT → Letta 平台，有状态 Agent 服务）。
对照本课："核心内存"≈ 本课 v2.0 全量注入的 MySQL user_profile；"外部存储+检索换入"≈ 下节课 v3.0 的 pgvector user_memory 按需检索。
Mem0 — 生产级长期记忆抽取与冲突消解四态机
思路：抽取-更新流水线 + 记忆冲突消解四态机（ADD / UPDATE / DELETE / NOOP）：当用户偏好反转（如预算从 5000 变 15000）时自动判定 UPDATE/DELETE，防止新旧记忆自相矛盾。
对照本课：≈ 本课 v2.0 UserProfileExtractor 的"旧画像+新对话 → LLM 合并更新"，将合并消解推广至全部长期记忆。
Zep（Graphiti 引擎）— 时序知识图谱
思路：记忆不是平面列表而是时序知识图——事实带生效/过期时间边，专治"偏好会变、旧事实会过期"的一致性问题。
对照本课：≈ user_profile（新覆盖旧 + updated_at）与下节课 user_memory（只增不改 + 时序检索）的工程简化版。
A-MEM — Agentic 记忆演化（学界前沿）
思路：记忆不是死档案：新记忆与旧记忆互链、自我组织与更新（Zettelkasten 式链接），让记忆随使用演化。
对照本课：我们的课程先保证记忆可信、可解释，再谈记忆自进化。
学界视角：forms / functions / dynamics 三分法
评价任何记忆系统，就问三个问题
forms（形态）记忆存在哪——模型参数里 / 上下文里 / 外部存储？
functions（功能）记忆承担什么——感觉缓冲 / 短期工作 / 长期沉淀？
dynamics（动态）记忆怎么动——写入、检索、更新、遗忘、演化？
用三问给课程三层记忆定位
Redis (短期缓冲) = 上下文内 / 短期工作（暂存、压缩、TTL 淘汰）；
MySQL user_profile (本课 v2.0 结论层) = 外部长期（合并更新、可更正）；
pgvector user_memory (下节课 v3.0 过程层) = 外部长期（语义检索）。
2026 记忆工程两大核心算子（冲突消解 + 三维检索打分）
① 记忆冲突消解四态机（Mem0 范式）：新记忆入库前对比已有记忆，路由至 ADD / UPDATE / DELETE / NOOP 四态，防止偏好反转（预算 5000→15000）引发自相矛盾。
② 三维记忆检索打分公式：Score = α·Relevance(语义相关度) + β·Recency(时间衰减) + γ·Importance(重要度)，兼顾语义匹配、近期优先与核心事实权重。
本课的选择：自建三层最小可控实现
把 Mem0 的"抽取-合并"与 Zep 的"时序覆盖"落在可控存储上（①托管 vs 自建 ②强时序 vs 简化版 ③静态 vs 自演化）。先用三层建立工程判断力，再决定是否引入托管底座。
