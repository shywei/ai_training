累积压缩流程（SummaryPipeline.java）
消息 > 8 条（SUMMARIZE_THRESHOLD = 8）-> 取前 N-4 条（含旧摘要）-> 快模型压缩 -> 写回 Redis（写入 session:{sid}:messages 列表）
第一次：超过 8 条 -> 累积摘要 A + 保留最近 4 条原文（KEEP_RECENT = 4）
第二次：再超 8 条 -> 累积摘要 B（合并旧摘要 A） + 4 条最新原文
不丢失历史，旧摘要 + 旧原文合并为新累积摘要
🚨 压缩与抽取双模选型
文本摘要压缩只做段落缩写，快模型（agent.model.summary，Qwen2.5-7B）即可胜任；但用户画像抽取涉及严格 JSON 结构，快模型极易发生语法残缺报错。画像抽取必须强制路由至推理模型（agent.model.reasoning，Qwen3-8B）。
