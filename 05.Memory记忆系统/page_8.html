上下文压缩 — Demo 实现

累积压缩流程
消息>8条 -> 取前N-4条(含旧摘要) -> 快模型压缩 -> 写回Redis
第一次：8条 -> 摘要A + 4条原文 = 5条
第二次：8条 -> 摘要B(含A) + 4条原文 = 5条
不丢失历史，摘要越来越完整
🚨 压缩与抽取双模选型
文本压缩只做段落缩写，快模型（Qwen2.5-7B）即可胜任；但用户画像抽取涉及严格 JSON 结构，快模型极易发生语法残缺报错。画像抽取必须强制路由至推理模型（Qwen3-8B）。
