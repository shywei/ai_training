# Page 2 — 目录

## Slide Objective
展示课程全景导航，让学员明确今天的学习路径、每个知识模块对应 Demo 的落地点，以及核心技术架构的升级点（六类记忆系统化分类、双库分层演进、全生命周期四大治理机制、Demo 教学简化与生产差异）。

## Suggested Presentation
带学员浏览 9 个章节的主线：
- **01 大模型的失忆症 (P3)：** 为什么 LLM 天生无状态，为什么必须由服务端工程构建记忆；
- **02 六类记忆分类与存储映射矩阵 (P4)：** 会话历史、工作记忆、短期、长期、画像、情景记忆六维全景；
- **03 Session Memory (P5–P6)：** 方案全景 + Redis 滑动窗口 Demo 实现；
- **04 上下文压缩 (P7–P8)：** 策略对比 + SummaryPipeline 滚动压缩 Demo 实现；
- **05 用户画像 (P9–P10)：** 设计模式 + UserProfileExtractor 异步抽取 Demo 实现；
- **06 context 注入演进 (P11)：** 从 v1.0 到 v4.0 的上下文装配演化；
- **07 记忆安全与隐私 (P12)：** 数据保留、PII 脱敏、GDPR / 个保法合规；
- **08 存储选型 + 分层演进 + 全生命周期治理 (P13–P16)：** 存储选型、结论/过程双库演进预告、写入/冲突/遗忘/并发全生命周期治理、五项生产差距；
- **09 Demo 架构 + 业界视野 + 总结 (P17–P19)：** v1.2.1 组件与日志、业界记忆系统（Letta/Mem0/Zep）、第五课收官总结。

## Key Emphasis
强调课程不仅有单机 Demo 的基础实现，更覆盖了企业生产级记忆架构的完整治理生命周期。
