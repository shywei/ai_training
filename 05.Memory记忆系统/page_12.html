CHAPTER 07

记忆安全与隐私 — 企业必须回答的问题

数据保留策略
Memory 不能无限增长。企业必须回答：
· Session 数据保留多久？
· 用户画像保留多久？
· 用户要求"忘记"怎么办？
· 谁有权删除用户数据？
PII 脱敏
用户画像可能包含敏感信息：
· 手机号、地址、身份证
· 支付偏好、消费金额
· 健康状况、个人习惯
存入数据库前必须脱敏。
合规要求
GDPR / 个保法要求：
· 用户有权查看自己的画像
· 用户有权要求删除
· 数据不能跨业务共享
· 需要审计日志
上下文泄露风险
画像和对话注入到 LLM 请求里。如果 LLM API 是第三方服务，数据就离开了企业边界。
解决方案：私有化部署 / 数据脱敏后发送 / 只发摘要不发原文。
Demo 中的处理
Demo 为了演示简单，没有实现 PII 脱敏和数据保留策略。
实际项目中，存入 MySQL 前必须做脱敏处理，需要增加数据删除接口。
