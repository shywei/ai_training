CHAPTER 04

上下文压缩 — 策略对比

滑动窗口
保留最近 N 条，裁掉旧的
✅ 简单、零成本
❌ 丢失早期信息
适用：短对话、对历史不敏感
累积摘要（Demo 选择）
旧消息→LLM压缩为摘要，摘要累积
✅ 不丢失历史
❌ 需要调用 LLM，有成本
适用：长对话、需要记住偏好
关键词抽取
提取关键实体存入结构化字段
✅ 精确、可查询
❌ 丢失上下文语境
适用：与画像系统配合
Embedding 压缩
对话转为向量，语义检索
✅ 语义级别
❌ 需要向量 DB
适用：超长对话、企业级
滑动窗口 + 累积摘要组合使用最常见。关键词抽取和 Embedding 作为补充。
🛠️ 进阶工程实践：Observation Masking（历史工具大返回折叠裁剪）
在引入 Tool Calling 的 Agent 中（第七、八课），真正撑爆 Context Window 的往往不是用户对话，而是历史轮次中动辄数 KB 的 JSON 工具返回结果（role=tool Observation）。生产系统通常对超过 N 轮之前的历史 role=tool 大返回做折叠掩码（Masking）或单行摘要替换（如替换为 [Tool output masked: 15 items returned]），仅保留最近 N 轮完整工具输出。
