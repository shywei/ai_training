// LlmRouter.java — 一次调用同时返回路由+模型
public RouteResult route(String userMessage) {
  // ... LLM 分类 ...

  Route route = result.contains("TOOL") ? TOOL
    : result.contains("KNOWLEDGE") ? KNOWLEDGE : CHAT;

  // 根据路由选择模型
  String model = switch (route) {
    case KNOWLEDGE, TOOL -> reasoningModel;
    default -> chatModel;
  };

  return new RouteResult(route, model);
}
Demo 已覆盖 · temperature=0 保证确定性输出
🚨 确定性路由与优雅降级
分类意图判定时，必须强制指定 temperature=0，否则随机性的输出容易产生意图颠倒。同时，在后端获取 mcpClient 绑定的 callback 时需做空指针防御与降级拦截，防止微服务启动顺序导致的进程挂起崩溃。
