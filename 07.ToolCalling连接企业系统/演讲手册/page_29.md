## Slide Objective
把 Demo 与生产的差距收敛成十二项清单，每项写全三格——**是什么问题 / 不解决会怎样 / 怎么解决（含具体技术方案与取舍）**。前七项（认证/权限/幂等/超时/审计/限流/补偿）中五项就是治理五件套的收口，后五项（缓存/监控/安全/Query Rewrite/Metadata Filtering）补工程闭环。这页的定位说清：这些不是"下一课的内容"，是学员做项目时要自己补的工程细节——治理五件套是放行 Agent 接生产系统的底线。

## Suggested Presentation
十二项逐个过，每项四拍：问题（对着 Demo 代码说）→ 不解决（说事故）→ 怎么办（说技术方案）→ 取舍（说代价）。不要平均用力，前七项和五件套咬合的可快讲（点"这页就是那五页的三格版"），后五项细讲。

**1 协议与认证**：Demo 是明文密码对比（`AuthController` 里 `user.getPassword().equals(password)`），且底层沿用早期有状态 SSE 会话，无 Token 与无状态网关机制。不解决：密码泄露即可冒用身份调 Tool，且无法横向扩容。怎么办：升级 **MCP 2026 无状态请求模型** + **OAuth 2.1** 标准鉴权与 JWT 令牌刷新，密码 BCrypt 哈希存储。**2 权限与危险分级**：任何 Agent 能调任何 Tool，无调用方身份校验与高危审批。不解决：低权限 Agent 调下单/删除类 Tool 就是越权事故。怎么办：建立**工具三级安全矩阵（Read/Write/Destructive）**，高危破坏性操作强制挂起走人机协同审批（HITL），配合 RBAC 权限表。**3 幂等**：无幂等键——`MemoryService.save()` 重复 INSERT，扩展写接口（如下单）重试即生成新单。不解决：超时重试 / LLM 重复调用 → 双下单、同一条记忆存多次。怎么办：idempotency-key（requestId/traceId+tool+参数哈希）+ 去重表/唯一索引 + 重复回放首次结果。取舍：去重表要有 TTL，键的归属方要约定。**4 超时**：`requestTimeout` 写死 10s/15s（`McpProductClient` / `McpKnowledgeClient`），不分查询/写入/批量，且 `v1.4` 尚无退避重试与熔断（第八课补齐）。不解决：慢查询挂住整轮对话；超时后裸重试造成重复执行。怎么办：分级超时（查询 3s/写入 10s/批量 30s）+ deadline 透传 + 退避加抖动 + 熔断降级。取舍：按下游 P99×1.5 起步，太紧误杀、太松无效。**5 审计**：`v1.4` 只到文本日志级（`McpToolCallback` 日志 + `logs/llm-*.log`），无结构化 Trace（第八课补内存 Trace）与持久化审计表。不解决：出事答不出"谁、何时、调了什么、结果"，合规过不了。怎么办：审计表（traceId/幂等键/参数与结果哈希/耗时/状态）+ 独立库只增不改 + PII 脱敏。取舍：全量快照存 PII 有风险，存哈希+脱敏快照。**6 限流**：无速率/并发控制，LLM 循环失控与注入批量调用直达下游。不解决：打挂 ERP、并发扣减超卖、被注入的 Agent 变成打别人的工具。怎么办：按 Tool 粒度限流（令牌桶/滑动窗口，Redis+Lua）+ 分层配额 + 写操作并发上限与乐观锁；超限排队/降级/429+Retry-After。取舍：配额从下游 SLA 反推。**7 补偿**：写操作失败即终止，无事前确认（第八课补 `ConfirmationService`）也无事后反向操作与跨系统对账。不解决：下单成功扣库存失败 → 超卖/压货，不一致靠客诉暴露。怎么办：正向/补偿 Tool 成对 + Saga（编排式/协同式）+ 本地消息表 + 定时对账。取舍：补偿链增加延迟与复杂度，只给需要一致性的写链路。

**8 缓存**：无缓存，相同问题每次检索 + 每次调 LLM 生成。不解决："推荐笔记本"问 100 次就是 100 次检索+生成，成本与延迟双高。怎么办：语义缓存（query Embedding 相似命中，Redis + TTL）。取舍：TTL 内给旧答案，价格/库存类问题禁用。**9 监控**：无指标采集，Tool 成功率、延迟、token 用量、成本都不可见。不解决：不知道哪个 Tool 慢、哪个失败率高，成本失控无人察觉。怎么办：成功率 / 延迟 P99 / token 与成本归因（Prometheus + Grafana），审计表聚合出报表。取舍：指标别贪多，先盯这三个。**10 运行时安全纵深**：入口有注入检测（`GuardrailsService`）、SQL 参数化，但 Tool 参数无业务白名单强校验、未防范间接提示词注入。不解决：参数伪造/注入绕过，外部数据污染上下文劫持模型。怎么办：**Tool 参数 Schema + 业务正则白名单强校验**，外部 Tool 返回清洗隔离，多租户上下文隔离。**11 Query Rewrite**：直接拿用户原文或简单拼接做 RAG 检索（`ShoppingAgentController.buildSearchQuery()` 仅把最近用户消息简单拼接），短 query 缺结构化产品意图。不解决："多少钱"这类追问检索不准，RAG 在复杂多轮下效果下降。怎么办：LLM 先抽意图（类别+需求+预算）生成结构化 query 再检索。取舍：多一次 LLM 调用，短 query/追问才触发。**12 Metadata Filtering**：`KnowledgeIndexer` 已把商品 JSON 存进 `vector_store.metadata`，但 `VectorSearchService.search()` 只按相似度过滤、没利用 metadata 列。不解决："推荐笔记本"搜到手机；按部门/租户无法隔离知识。怎么办：metadata 存 category/brand/price_range/tenant，先过滤再向量搜索。取舍：标签维护有成本，过滤过严会漏召回。

收尾把判断标准立住：**出事故的从来不是"调不通"，是"调太多、调重复、调一半、说不清"**——十二项里 3~7 是放行底线，其余是长期工程债，学员做项目时按"不解决会怎样"的代价排序补。

## Key Emphasis
必须讲清：① 每项都必须落满三格，"怎么办"里要有具体技术方案（令牌桶/唯一索引/审计表/语义缓存/Metadata 过滤……）而不是"要做限流"这种正确废话；② 十二项与五件套的关系（3~7 就是五件套，2 权限和 10 安全是它的外围）。不要展开任何一项的实现细节（OAuth2 流程、Prometheus 配置、Redis 缓存结构）——每项的展开深度止步于"方案名 + 取舍"，细讲留给各自专题页（3~7）和练习。

## Optional Extension
**学员问：十二项都要做吗？一个迭代根本排不下。**
答：按"事故代价 × 实现成本"排序，分三批。
Demo 做法：先在 Demo 里把成本最低的三件补上找手感——BCrypt（认证最低限）、幂等键（半天）、Guava 限流（一小时），都有现成锚点（`AuthController` / `MemoryService.save()` / `McpToolCallback` 练习 5）。
生产做法：放行前底线是 3~7（五件套）+ 2（权限）；8/9（缓存/监控）在流量与成本上来后上，监控可以在审计表上聚合先出报表再上 Prometheus；10~12 随 RAG 与安全评审推进。取舍：先保命（幂等/限流/补偿）再省钱（缓存/监控）再做深（Query Rewrite/Metadata Filtering），反过来做就是精致的事故现场。

**学员问：这些能力以后会不会框架/平台直接就有了，不用自己做？**
答：会有一部分被接管，但被接管的是"怎么做"，不是"要不要做、配多少"。
Demo 做法：手搓一遍（练习 4~7）搞清每项治理的语义——比如幂等键的判重点在调用方还是 Tool 端。
生产做法：第九课会看到 AgentScope Java 2.0 这类框架接管的是胶水层（连接、协议、会话、事件流），治理策略本身仍是你的业务决策；平台化阶段（第十一课支柱一「AI 网关与成本治理」）限流/审计/RBAC 会沉到 MCP Gateway 统一做，但配额、留存期、补偿对还是架构师定。取舍：跳过手搓直接上平台，配置错了都不知道错在哪——先懂语义再用工具，这也是本课坚持手搓治理的原因。

## Classroom Interaction
给十二项做"事故定价"：把 3~7 五项打乱写在白板上，让学员各自标注"不解决最先出哪类事故、代价多大"（双下单/打挂 ERP/超卖/合规追责/挂死对话），再排出团队内的实施顺序——排完对照"先保命再省钱再做深"的标准答案，讨论分歧。

## Take Away
差距清单的价值在三格不在清单：每项写清"是什么问题 / 不解决会怎样 / 怎么解决（含方案与取舍）"，按事故代价排序落地——3~7 五件套是放行 Agent 接生产系统的底线，其余是工程债，可以欠但要知道欠着。

## Why This Slide Matters
跳过这页，学员会拿着"Demo 能跑"的系统直接面对生产评审，被十二类问题逐一问倒：密码明文、双下单、慢查询挂死、出事无记录、下游被打挂、半截单没人收——每一项都是课件里写着"不解决会怎样"、却要在事故里重新学一遍的东西。
