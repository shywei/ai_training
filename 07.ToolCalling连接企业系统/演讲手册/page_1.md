## Slide Objective
开场定调：从"记住用户"进入"让 Agent 连接企业系统"。建立第七课的认知框架——Agent 只能"读"是不够的。

## Suggested Presentation
上节课让导购 Agent 懂了商品知识，记住了用户偏好。RAG 检索让它能推荐商品，记忆系统让它能记住用户。但它还是只能"说"，不能"做"。

用户问"ThinkPad X1 多少钱"，Agent 只能从向量库里找到描述信息——"ThinkPad X1 Carbon Gen12，联想，笔记本电脑"。没有价格，没有库存。因为向量库存的是商品描述，不是实时数据。价格每天在变，库存每分钟在变，这些数据不应该放向量库。

用户说"记住我喜欢轻薄本"，Agent 被动等系统提取。`UserProfileExtractor` 每 5 轮对话触发一次，用 LLM 从对话中提取画像。但用户明确说了"记住"，Agent 不能立刻响应，要等下一次提取周期。

用户说"帮我下单"，Agent 完全无能为力。它没有调用订单系统的能力。

这三个问题的本质是一样的：Agent 缺少"做事"的能力。第七课要解决这个问题。

## Key Emphasis
三个问题不是独立的，它们指向同一个缺失：Agent 和外部系统之间缺少连接机制。第六课的 Agent 是一个"孤岛"——它有知识、有记忆，但不能和外部世界交互。
