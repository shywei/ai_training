CHAPTER 02

核心问题 — 怎么让 LLM "做事"？

LLM 天生的局限
LLM 只能生成文本
它不能访问互联网、不能查数据库、不能调 API
它的"知识"来自训练数据，有截止日期

但企业场景需要：
查实时价格 · 查库存 · 下单 · 发邮件 · 更新 CRM
这些 LLM 都做不到
解决方案：Function Calling
LLM 不直接执行，而是返回"我要调用什么函数、传什么参数"
系统执行函数，把结果回传 LLM
LLM 基于结果生成最终回复
类比
🧠 LLM = 大脑
理解意图、做决策、生成回复
🔧 Tool = 手脚
查数据库、调 API、写文件、发消息
📋 Function Calling = 指令
大脑告诉手脚"做什么、怎么做"
本课要解决三个问题：
怎么告诉 LLM 有哪些工具？ · LLM 怎么决定用哪个？ · 工具怎么标准化？
