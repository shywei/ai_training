CHAPTER 04

Tool vs Resource — 什么时候用哪个

Tool
LLM 决定调用
动态查询/写入
参数可变
类比 POST
Resource
Client 主动读取
静态上下文
URI 固定
类比 GET
选型决策树
需要 LLM 决定是否调用？→ Tool
数据量大、需要搜索？→ Tool
会话开始加载一次？→ Resource
数据相对稳定？→ Resource
全量加载合理？→ Resource
Demo 中的选型理由
Tool search_knowledge — 需要语义搜索，数据量增长
Tool search_memory — 持续增长，需要语义搜索
Tool search_memory — 语义检索用户记忆
Tool queryProductInfo — LLM 决定何时查价格
Resource user://{userId} — 会话开始加载一次，稳定
🚨 严禁乱用 Resource 注入
即使商品库极小（如 26 个商品），也不应通过 Resource 一次性全量加载。全量加载不仅会引起 Token 膨胀，而且将检索压力丢给大模型会导致命中精确度大幅下降。必须使用带语义过滤能力的 Tool 动态返回 Top-K 结果。
