CHAPTER 09

LLM 路由 — 三种方案对比

方案一：关键词过滤
匹配"多少钱"→ TOOL
匹配"推荐"→ KNOWLEDGE
默认 → CHAT
✗ 局限
"帮我看看那个笔记本"不含"推荐"
第六课用过，已淘汰
方案二：Embedding 相似度
预定义意图描述
用户消息 Embedding 后
和意图描述做相似度匹配
△ 中等
需要维护意图描述，新增意图要更新
仅 PPT 讲解
方案三：LLM 分类 ✓
用快模型做三分类
KNOWLEDGE / TOOL / CHAT
语义理解，准确率高
✓ 优势
不需维护规则，语义理解，成本低
Demo 采用
选型建议：意图分类少（< 10）用 LLM；意图多（> 50）考虑 Embedding；规则明确用关键词
实际项目中三种方案可以混合使用：先关键词快速匹配，匹配不上再用 LLM
