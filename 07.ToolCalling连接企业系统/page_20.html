CHAPTER 06

数据分层 — 第六课 vs 第七课

第六课：Agent 直连数据库
商品知识 → RetrievalService → pgvector
用户记忆 → UserMemoryMapper → pgvector
用户画像 → UserProfileMapper → MySQL
价格库存 → ❌ 第六课没有
问题：Agent 和数据库耦合
换数据库 → 代码要改
其他 Agent 不能复用
第七课：全部通过 MCP
商品知识 → MCP Tool → knowledge-server → pgvector
用户记忆 → MCP Tool → knowledge-server → pgvector
用户画像 → MCP Resource → knowledge-server → MySQL
价格库存 → MCP Tool → product-server → MySQL
agent-runtime 不直接访问任何数据库
解耦 · 复用 · 标准化 · 独立部署
RAG 检索优化（Demo 未覆盖）
Metadata Filtering：metadata 字段存结构化标签（category/brand/price_range），查询时先过滤再向量搜索
Query Rewrite：LLM 先抽取意图生成结构化 query，再做检索（不直接用用户原文）
