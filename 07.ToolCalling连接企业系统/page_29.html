CHAPTER 07 · 生产落地

Demo vs 生产 — 十二项差距对照（问题 / 风险 / 落地标准）

1 协议与认证
问题：明文密码，且沿用早期有状态 SSE 会话，多实例网关难扩展。
怎么办：升级 MCP 2026 无状态请求模型 + OAuth 2.1 标准鉴权与 JWT 令牌。
2 权限与危险分级
问题：任何 Agent 能调所有 Tool，高危操作无审批拦截。
怎么办：工具三级安全矩阵（Read/Write/Destructive），高危强制挂起走人机协同审批（HITL）。
3 幂等
问题：无幂等键：save_memory 重复 INSERT，重试产生重复订单。
怎么办：强制绑定 idempotency-key（requestId+参数哈希）+ Redis/DB 唯一去重表。
4 超时与容错
问题：写死 10s/15s，超时无退避重试与熔断（第八课手写补齐）。
怎么办：分级超时（读 3s/写 10s）+ 指数退避抖动重试 + 熔断降级。
5 审计留痕
问题：仅控制台文本日志，无全链路分布式 Trace 与持久化审计。
怎么办：审计表（traceId/租户/参数结果哈希/耗时/状态）+ 敏感字段脱敏存储。
6 限流与防雪崩
问题：无速率限制，模型死循环批量调用可瞬间击垮下游 ERP。
怎么办：按 Tool 配置分布式令牌桶/滑动窗口限流，超限触发 429 降级保护。
7 事务与补偿
问题：跨系统写操作失败即终止，无反向冲正与对账。
怎么办：正向/补偿 Tool 成对设计，结合 Saga 事务与定时对账补偿。
8 缓存优化
问题：无语义缓存，相同问题每次都触发高延迟检索与模型生成。
怎么办：语义缓存（Embedding 向量匹配命中 + TTL），价格库存等强一致场景禁用。
9 观测与指标
问题：缺少 Tool 成功率、延迟 P99、Token 消耗与成本归因。
怎么办：接入 Prometheus + Grafana 指标看板，与 OpenTelemetry Trace 联动。
10 运行时安全纵深
问题：Tool 入参无白名单校验，未防范间接提示词注入。
怎么办：入参正则白名单严格校验 + 多租户上下文隔离 + 外部返回清洗隔离。
11 Query 改写与 RAG
问题：直接拿用户简短原文搜索，多轮追问上下文缺失导致召回失败。
怎么办：检索前执行语义 Query Rewrite，补齐商品实体与意图约束。
落地判断红线
Demo 侧重验证协议连通与功能原型；生产落地必须守住安全授权矩阵与治理五件套两条底线。
