CHAPTER 04

Function Calling 协议 — OpenAI API 格式

请求：functions 参数定义可用工具
{
  "model": "Qwen2.5-7B",
  "messages": [...],
  "functions": [
    {
      "name": "queryProductInfo",
      "description": "查询商品价格和库存",
      "parameters": {
        "type": "object",
        "properties": {
          "productId": {
            "type": "string",
            "description": "商品ID"
          }
        },
        "required": ["productId"]
      }
    }
  ]
}
Spring AI 的 FunctionCallbackWrapper 自动生成这段 JSON
Demo 已覆盖（自动封装，开发者不直接写）
响应：tool_call 指令
{
  "choices": [{
    "message": {
      "role": "assistant",
      "content": null,
      "tool_calls": [{
        "id": "call_abc123",
        "type": "function",
        "function": {
          "name": "queryProductInfo",
          "arguments": "{\"productId\":\"NB001\"}"
        }
      }]
    }
  }]
}
🚨 调试识伪：正常调用非报错
在调试日志中，当看到响应包 choices[0].message.content 字段为 null，且含有 tool_calls 指令时，这是正常的协议流而非模型异常或故障。必须通过 SDK 注册的 Callback 执行本地服务后再次发送回执才能继续生成。
