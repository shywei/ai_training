CHAPTER 02

Function Calling — 概念与流程

完整流程（6 步）
① 定义函数：名称 + 描述 + 参数 Schema
② 注册到 LLM 请求（OpenAI 协议 tools 参数，旧版 functions 已废弃）
③ 用户提问 → LLM 判断是否需要调用工具
④ LLM 决策输出：仅返回结构化 tool_calls JSON（不执行任何代码）
⑤ 调度执行：参数校验与鉴权（本地工具宿主沙箱执行，远程工具分发 MCP Server 执行）
⑥ 结果组装回传 LLM（role=tool 消息）→ LLM 基于证据生成最终回复
实际例子
用户说：
"ThinkPad X1 多少钱"
LLM 返回（不是最终回复，而是结构化 tool_calls JSON 决策）：
{
  "tool_calls": [{
    "id": "call_abc123",
    "type": "function",
    "function": {"name": "queryProductInfo", "arguments": "{\"productId\":\"NB001\"}"}
  }]
}
Agent Runtime 校验入参并调用 MySQL 后回传，LLM 生成最终回复：
"ThinkPad X1 Carbon 当前售价 ¥9999，库存 58 件，在售。"
核心权力边界与沙箱职责划分：大模型仅负责输出结构化 Tool Call 请求。
Agent Runtime / Host 负责参数校验、权限判定与调度；本地工具由宿主沙箱执行，远程工具由 MCP Server 及其宿主环境执行，各执行环境分别承担相应的沙箱隔离与安全责任。
