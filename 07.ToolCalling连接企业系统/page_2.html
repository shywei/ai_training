CHAPTER 01

第六课回顾 — Agent "懂"了什么

✓ RAG 知识检索
Agent 能检索商品知识，引用配置和亮点推荐
✓ 记忆增强
pgvector 语义检索，自动沉淀 + 记忆增强
✓ 数据分层
描述放 pgvector，价格库存放 MySQL
✓ Agent 直连数据库
RetrievalService → pgvector，UserProfileMapper → MySQL
但 Agent 只能"读"，不能"做"
"ThinkPad X1 多少钱"
→ Agent 只能找到描述，不知道实时价格

"帮我下单"
→ Agent 无法调用订单系统

"记住我喜欢轻薄本"
→ Agent 被动等系统提取，不能主动保存
第七课目标
查实时数据 · 调用企业系统 · 主动保存偏好 · 统一协议访问
