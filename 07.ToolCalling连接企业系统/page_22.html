CHAPTER 07

Demo vs 生产 — 具体差距

认证
Demo：明文密码对比
生产：OAuth2 + JWT + Token 刷新 + 密码 BCrypt 哈希
权限
Demo：任何 Agent 能调任何 Tool
生产：RBAC 权限表，哪些 Agent 能调哪些 Tool，审批流程
幂等
Demo：不处理，LLM 可能重复调用
生产：请求 ID 去重，Tool 保证重复调用无副作用
超时
Demo：写死 15 秒
生产：分级超时（查询 3s / 写入 10s / 批量 30s）+ 指数退避重试 + 熔断
审计
Demo：只写日志
生产：审计表记录（谁、什么时间、调了什么、参数、结果、耗时），可追溯可回放
缓存
Demo：无缓存，每次都查数据库
生产：语义缓存（相似 query 命中缓存），减少 LLM 调用和数据库查询
监控
Demo：无监控
生产：Tool 调用成功率、延迟 P99、LLM token 用量、成本归因
安全
Demo：无输入校验
生产：SQL 注入防护、PII 脱敏（手机号只存前三位后四位）、Tool 参数校验
Query Rewrite
Demo：直接用用户原文做 RAG 检索
生产：LLM 先抽取意图（类别+需求+预算），生成结构化 query 再检索
Metadata Filtering
Demo：所有信息塞进 content 字段
生产：metadata 存结构化标签，查询时先过滤再向量搜索
