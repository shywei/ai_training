CHAPTER 13

save_memory — 跨路由 Tool + Prompt 配套

问题：用户随时可能表达偏好
CHAT："我预算8000" → 应该保存偏好
KNOWLEDGE："我喜欢轻薄本" → 应该保存偏好
TOOL："这个太贵了" → 应该保存偏好
解决方案：跨路由注册
save_memory 不限于 TOOL 路由
所有路由都注册，LLM 在任何对话中都能调用
Prompt 配套（记忆使用规则）
# 记忆使用规则
- 如果「参考信息」中有用户记忆，
  请结合记忆个性化推荐
- 当用户表达偏好、需求、约束时，
  主动调用 save_memory 保存
- 不需要每次都保存，
  只保存有价值的信息
Tool 注册策略对比
queryProductInfo 仅 TOOL 路由 只有查价格时需要
save_memory 所有路由 用户随时表达偏好
不是暴露 Tool 就够了，还要告诉 LLM 什么时候用
Tool + Prompt = 完整的 Agent 能力
