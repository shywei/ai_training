CHAPTER 06

ReAct 模式 — Function Calling 的思想基础

ReAct = Reasoning + Acting
🧠 Reason（推理）
LLM 分析当前情况，决定下一步该做什么
↓
🔧 Act（行动）
调用工具获取外部信息或执行操作
↓
👁️ Observe（观察）
获取工具返回的结果
↓
🔄 循环
基于观察结果继续推理，直到任务完成
实际例子：多步推理
用户："拯救者和 MacBook 哪个便宜？"
推理1：需要查两个商品的价格
行动1：调用 queryProductInfo("NB003")
观察1：拯救者 ¥8999
推理2：还需要查 MacBook 的价格
行动2：调用 queryProductInfo("NB002")
观察2：MacBook ¥14999
推理3：8999 < 14999，拯救者更便宜
回复："拯救者 ¥8999 更便宜"
Function Calling 是 ReAct 的工程实现
ReAct 是 2022 年 Google 的论文提出的思想
Function Calling 是 OpenAI 将 ReAct 工程化的方案
LLM 每次 tool_call 就是一次 Reason→Act→Observe
为什么这很重要？
理解 ReAct，才能理解为什么 LLM 会"决定"调用工具——这不是随机的，是推理的结果
