CHAPTER 02

两种实现方式 — @Tool vs FunctionCallbackWrapper

方式一：@Tool 注解（Spring AI 1.0.0+ GA）
@Tool(description = "查询商品价格")
public String getPrice(
  @ToolParam("商品ID") String productId
) {
  return productRepo.getPrice(productId);
}
✓ 声明式，简洁，自动提取 JSON Schema
方式二：FunctionCallbackWrapper（M4 版本）
Function<Map, String> fn = args -> {
  return productRepo.getPrice(
    (String) args.get("productId"));
};

FunctionCallbackWrapper.builder(fn)
  .withName("getPrice")
  .withDescription("查询商品价格")
  .build();
✓ 编程式，灵活，手动控制 Schema
