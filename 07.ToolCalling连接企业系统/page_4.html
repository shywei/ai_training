CHAPTER 03

Function Calling — 概念与流程

完整流程（6 步）
① 定义函数：名称 + 描述 + 参数 Schema
② 注册到 LLM 请求（functions 参数）
③ 用户提问 → LLM 判断是否需要调用函数
④ LLM 返回 tool_call（函数名 + 参数）
⑤ 系统执行函数，把结果回传 LLM
⑥ LLM 基于结果生成最终回复
实际例子
用户说：
"ThinkPad X1 多少钱"
LLM 返回（不是最终回复，而是 tool_call）：
{
  "tool_call": {
    "name": "queryProductInfo",
    "arguments": {"productId": "NB001"}
  }
}
系统执行后回传结果，LLM 最终回复：
"ThinkPad X1 Carbon 当前售价 ¥9999，库存 58 件，在售。"
关键：LLM 决定"要不要调、调什么、传什么参数"
系统负责"执行"，LLM 负责"决策"
