CHAPTER 01

核心问题 — 怎么让 LLM "做事"？

LLM 天生的局限
LLM 只能生成文本
它不能访问互联网、不能查数据库、不能调 API
它的"知识"来自训练数据，有截止日期

但企业场景需要：
查实时价格 · 查库存 · 下单 · 发邮件 · 更新 CRM
这些 LLM 都做不到
解决方案：Function Calling
LLM 不直接执行，而是输出决策 JSON（"调什么工具、传什么参数"）
宿主环境（Agent Runtime）校验参数并实际执行物理调用
执行结果作为 Tool 消息回传，LLM 最终生成自然语言总结
执行权力边界（铁律）
🚨 彻底纠偏：大模型绝无物理执行权
大模型（LLM）是认知决策引擎，只负责输出结构化的 Tool Call JSON，本身绝不执行任何实际代码或物理动作！
工具调用的实际执行权、入参校验、权限鉴权、沙箱隔离与异常捕获完全且唯一归属于 Agent Runtime / Host 环境。
🧠 LLM = 参谋 / 决策者
理解意图、结构化提取参数、给出调用建议（无执行权）
🛡️ Agent Runtime = 执政官 / 执行者
入参安全校验、权限控制、物理网络调用、捕获异常与限流
本课解决核心三问： 如何注册工具规范？ · Runtime 如何安全执行？ · MCP 协议如何统一生态？
