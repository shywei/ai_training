CHAPTER 03 · 安全治理

企业级工具安全授权矩阵 — 权限分级 · 人机协同审批 · 运行时防线

工具危险等级三级授权矩阵（按风险严格分流）
🟢 只读查询（Read） 直接放行 · 频控脱敏
典型工具：queryProductInfo、search_knowledge、queryStock
影响评估：无系统状态修改，纯信息检索与只读查询。
安全策略：Agent Runtime 直接放行调用；实施读取速率限制（Rate Limiting）、敏感数据动态脱敏与多租户上下文隔离。
🟡 写操作（Write） 参数校验 · 强制幂等
典型工具：save_memory、addToCart、updateProfile
影响评估：产生状态变更与数据增改，但业务上可追溯、可补偿或可逆回滚。
安全策略：运行时入参白名单严格校验 + 强制绑定幂等键（Idempotency Key），结合租户权限校验，杜绝重复写入与非法篡改。
🔴 高危破坏性操作（Destructive） 强制挂起 · 人机协同审批
典型工具：place_order（资金支付）、delete_record（数据销毁）、transfer_funds
影响评估：涉及真实资产转移、不可逆破坏、法律契约或核心系统配置变更。
安全策略：绝对禁止大模型自主静默执行！必须由 Agent Runtime 强制挂起状态机，触发人机协同审批（Human-in-the-Loop Approval），用户显式确认后方可调用。
Agent Runtime 运行时四重防御纵深
🛡️ 1. 运行时参数白名单校验（Whitelist Validation）
绝不信任 LLM 输出的参数。除 JSON Schema 类型校验外，对商品 ID、数值范围、日期格式执行业务白名单正则过滤，杜绝 SQL 注入与命令拼接。
🏢 2. 多租户 RBAC 鉴权与数据隔离（Tenant Isolation）
Tool 执行前严格校验调用主体身份。透传当前用户 tenantId，禁止 Agent 利用模型幻觉越权（IDOR）访问跨租户、跨部门的未授权数据。
⏱️ 3. 访问速率限制与防循环（Rate Limiting）
按 Tool 粒度实施分布式令牌桶限流。防范 Agent 因 Prompt 提示词注入攻击陷入死循环批量调用，保护下游 ERP 与支付系统不被瘫痪。
🦹 4. 防间接提示词注入（Indirect Injection Defense）
外部 Tool（如网页抓取、知识库文档）返回内容在组装回传大模型前，必须经过敏感清洗与证据隔离标签包裹，防止夹带恶意指令劫持后续对话。
架构准则： Tool 不是普通的 RPC 接口，而是企业与大模型交互的第一道安全边界。 只读放行、写操作控幂等、高危破坏性必经审批、全链路强制校验，这是企业级 Agent 准入生产的刚性底线。
