CHAPTER 03

MCP 协议 — 为什么需要标准协议

不用 MCP 的做法
Tool 代码直接写在 Agent 项目里
Agent 直连数据库、直连外部 API
换框架 → 代码重写
换 Agent → Tool 不能复用
每个 Agent 都写一遍 → 重复劳动
MCP 的做法
Tool 独立部署为 MCP Server
Agent 作为 MCP Client，通过标准协议调用
换框架 → 只改 Client，Server 不变
换 Agent → MCP Server 通用
一次开发，到处复用
类比
REST API → Web 服务间标准协议
前端不用关心后端用什么语言/框架
USB → 硬件设备间标准协议
键盘不用关心电脑用什么操作系统
MCP → AI Agent 与 Tool 间标准协议
Agent 不用关心 Tool 用什么实现
MCP = Model Context Protocol
Anthropic 2024 年底提出，已开源
不是 Anthropic 独占，是开放标准
