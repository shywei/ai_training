CHAPTER 06

MCP 核心概念 — 四大能力

🔧 Tools
LLM 可调用的函数
搜索、查询、写入、计算
LLM 决定何时调用
MCP 协议定义：
// Server 暴露 Tool
Tool {
  name: "queryPrice"
  description: "查价格"
  inputSchema: {
    type: "object"
    properties: {
      id: {type:"string"}
    }
  }
}

// Client 调用
callTool("queryPrice",
  {id:"NB001"})

📄 Resources
Client 可读取的数据
文件、配置、上下文
Client 主动读取
MCP 协议定义：
// Server 暴露 Resource
ResourceTemplate {
  uriTemplate:
    "user://{userId}"
  name: "用户画像"
  description: "读画像"
  mimeType: "application/json"
}

// Client 读取
readResource(
  "user://U001")
// → 返回 JSON 画像

💬 Prompts
预定义的 Prompt 模板
Server 提供，Client 选择使用
声明式能力暴露
MCP 协议定义：
// Server 暴露 Prompt
Prompt {
  name: "analyze-review"
  description: "分析评论"
  arguments: [{
    name: "review"
    description: "评论内容"
    required: true
  }]
}

// Client 获取 Prompt
getPrompt(
  "analyze-review",
  {review: "..."})
