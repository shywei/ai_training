## Slide Objective
展现 01B《AI 认知进阶（可选深潜）：大模型底层工程与算力机理》的整体知识地图与章节逻辑。帮助学员建立结构化心智模型，清晰理解五大章节如何从扩展律前沿递进到推理拓扑、训练流水线、算力底座，并最终反哺架构设计。再次明确本课专为技术 Leader 与资深工程师打造，普通学员可跳过直接进入第 02 课。

## Suggested Presentation
在进入第一个具体技术点之前，我们先花两分钟总览全课的五大进阶核心篇章。

承接第 01 课的宏观认知，整个 01B 课程的设计逻辑是一条极其严密的工程递进链：
- **第一章【扩展律前沿与推理全景】（P03 - P04）**：我们首先从扩展律的最新变迁切入。过去大家只知道“堆算力和语料”，但 2024–2026 年行业发生了关键转折——从单纯的预训练扩展，迈向了推理时思考扩展（Test-Time Compute）。紧接着，我们用一张端到端张量计算图，把 Prompt 转化为 Next Token 的完整拓扑全景建立起来。
- **第二章【模型推理核心机理】（P05 - P09）**：这是核心计算单元的显微镜。我们将深入拆解 BPE 分词算法及其在工程中的深坑，解析 Embedding 高维空间流形与 RoPE 旋转位置编码的复数外推机制，剖析从 MHA 到 GQA 的降维工程，理解 Temperature 与 Top-P 采样微积分，并彻底厘清 Prefill 计算密集与 Decode 访存密集背后的 KV Cache 机制。
- **第三章【现代模型训练范式与前沿架构】（P10 - P14）**：我们将揭开大模型从 0 到 1 的四阶段流水线（Pre-training ➔ SFT ➔ RLHF/DPO ➔ RLVR），重点解释为什么具备确定性校验器的代码和数学催生了强化学习慢思考；随后剖析千亿 MoE 稀疏路由与 Native Omni 原生全模态技术。
- **第四章【模型文件、量化与算力底座】（P15 - P18）**：走出算法层面，走向物理世界。剖析 Safetensors 与 GGUF 的底层文件组织，拆解 INT8/INT4 量化与反量化补偿算法，给出架构师必备的显存精准速算黄金公式，并深入 GPU HBM 带宽墙与 vLLM/SGLang PagedAttention 显存池化调度。
- **第五章【物理边界、架构反哺与全栈选型】（P19 - P22）**：最后收官升维。剖析裸模型的四大物理边界，揭示底层机理如何直接决定 RAG 切块策略、Agent 工具调用与成本路由设计，给出公有云、本地量化与私有化微调的三大选型决策树，打通全栈认知。

## Key Q&A / Clarifications
**Q：普通学员如果不学 01B，对后续课程会有阻碍吗？**
A：完全没有阻碍！整个培训体系采用了清晰的分层设计：第 01 课是全员必修的认知基石，第 02 课是全员动手实战的核心。而 01B 是面向项目 Leader、架构师或对算力显存有深度诉求的工程师的“可选深潜”。普通学员在掌握了第 01 课的宏观心智后，直接进入《第 02 课：AI辅助编程入门》是最顺畅、最高效的学习路线。
