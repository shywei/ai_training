## Key Q&A / Clarifications
**Q：在 Prompt 拼接时，为什么把时间戳（如 `Current Time: 2026-11-02 10:30:15`）放在 System Prompt 第一行会导致推理成本大幅上升？**
A：因为主流高性能推理引擎（vLLM / SGLang）以及公有云厂商（如 OpenAI、DeepSeek、Anthropic）都支持 Prompt Cache（前缀缓存）。前缀缓存是基于从头开始的最长公共前缀 Token 哈希匹配的。如果你把每秒都在变化的时间戳放在最前头，系统就会判定前缀发生了改变，导致后续数千字本来可以复用的 System Prompt 全部无法命中缓存，每次都要全量重新进行 Prefill 计算与全额计费！正确的做法是把静态规范放最前，把动态时间戳移到最末尾。
