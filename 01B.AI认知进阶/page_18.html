CHAPTER 04 · 模型文件、量化与算力底座

调度革命：PagedAttention、Continuous Batching 与推理性能权衡

现代推理引擎（vLLM/SGLang）的核心突破：通过内存分页与迭代级调度打碎气泡，并在并发、吞吐与延迟之间进行精准权衡。
显存池化 PagedAttention (vLLM)
OS 虚拟内存分页哲学的完美复刻
• 打破连续物理预分配：传统必须为每个请求预留 8K 连续显存，碎片率高达 80%！
• Block / Page 离散分页：以 16/32 Token 为一页，显存按需分配，通过逻辑页表（Block Table）在物理离散显存中动态缝合序列。
收益：内部碎片从 80% 降至 < 4%，同硬件显存并发直接提升 2~4 倍！
算力调度 Continuous Batching (Orca)
Iteration 级别微调度，彻底消除气泡
• 告别传统静态批处理（Static Batching）：以前必须等整批中最慢的请求生成完才能接新批次；
• 步长级别动态插拔：每个生成 Token 步长检查状态，短请求一旦结束立刻释放显存槽位，新排队请求毫秒级填补空缺。
收益：消除 GPU 闲置等待“气泡（Bubbles）”，服务吞吐量再暴增 3 ~ 5 倍！
架构师必须掌握的推理性能四大指标权衡矩阵（Trade-off Matrix）
高吞吐 vs 低延迟的永恒博弈
并发数 (Concurrency C)
系统同时处理的请求量。受总显存容量与 KV Cache 池制约。
总吞吐量 (Throughput)
Tokens/s。随 Batch 增大而显著上升，衡量硬件整体产出效率。
首字延迟 (TTFT)
Time to First Token。取决于 Prefill 计算速度，算力受限（Compute-Bound）。
字间延迟 (TPOT)
Time per Output Token。Decode 每吐一字的耗时，访存带宽受限（Memory-Bound）。
Automatic Prefix Caching (APC)： 跨多并发共享 System Prompt 与知识库上下文，仅保留一份物理内存页，TTFT 暴跌 80%！
Chunked Prefill 算力平滑化： 将超长 Prompt 切块与 Decode 混合批处理，彻底消除线上大请求导致的卡顿与 TPOT 剧烈抖动。
