Embedding 向量流形与 RoPE 旋转位置编码直觉

将离散 ID 映射为连续高维向量流形，并通过复数旋转巧妙刻画相对位置，是大模型理解长程语义的数学基石。
语义空间 Embedding Manifold
高维连续语义流形与向量距离
每个离散 Token ID 映射到 $d_{model}$（如 4096 或 8192）维的高维空间。 语义相近的词在高维流形上具有更小的欧氏距离和相近的余弦夹角：
cos_sim(Embedding("Java"), Embedding("Python")) ≈ 0.82
cos_sim(Embedding("Java"), Embedding("香蕉")) ≈ 0.12
早期局限 Absolute Positional Embedding
为什么传统“绝对位置编码”彻底失效？
早期 Transformer（如 BERT、GPT-2）为每个绝对下标分配一个固定向量：$x_i = e_i + p_i$。
致命死穴：
1. 无法泛化相对距离：位置 1 与位置 2 的关系，和位置 1001 与位置 1002 完全割裂；
2. 无法长文本外推：预训练只训了 4K 长度，遇到第 4097 个位置，位置向量根本不存在，直接崩溃！
RoPE（Rotary Position Embedding）旋转位置编码与长上下文外推
现代 LLM 标配 · LLaMA / Qwen / DeepSeek
1. 复数二维旋转机制：
将 Query 与 Key 向量的每两个相邻维度视作复平面的二维向量，位置为 $m$ 的 Token 乘以旋转矩阵 $R_{\Theta, m}$（逆时针旋转 $m\theta$ 角度）。
2. 点积内积相对不变性：
在计算注意力点积时：$\langle R_m q, R_n k \rangle = q^T R_{n-m} k$。旋转使得两者的注意力只严格取决于相对位移 $(m - n)$，且距离越远内积自然衰减！
3. 128K~1M 超长外推（YaRN）：
利用频率插值（NTK-aware / YaRN），平滑压缩高频波长与低频旋转角，模型无需从头预训练，即可将上下文长度从 4K 无损扩展到 128K~1000K。
