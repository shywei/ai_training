CHAPTER 01 · 扩展律前沿与推理全景

扩展律前沿：2024–2026 双引擎 Scaling Laws 深度解剖

从单向依赖“海量语料预训练”到“预训练 + 推理时慢思考”双轮驱动，大模型的算力消耗范式正在经历根本性重构。
第一引擎 · 经典底座 Pre-training Compute Scaling
预训练计算扩展与“数据墙”瓶颈
Chinchilla 核心定律：模型参数量（$N$）与预训练 Token 数量（$D$）应同比例扩展，计算预算 $C \approx 6ND$。
边际效应递减与数据墙：全球高质量公共文本已在 2024 年被各家大模型基本爬取殆尽，仅靠增大预训练规模，单位 FLOPs 带来的智力增益已显著放缓。
定位：决定模型的世界常识与直觉基座（快思考 System 1，类似人脑的瞬间直觉反应）。
第二引擎 · 前沿突破 Test-Time Compute Scaling
推理时思考扩展与强化学习自我进化
Inference Scaling 定律：给定基础模型，在推理阶段消耗更多的思考 Token 算力，复杂任务的准确率呈对数线性飙升。
自主反思与试探回溯：DeepSeek-R1 / OpenAI o1 通过大规模 RL 训练，模型在输出最终答案前，自主生成成千上万个 <think> 标记进行假设验证与自我纠错。
定位：开启慢思考深思熟虑范式（慢思考 System 2，类似数学家草稿纸上的长链推导）。
算力分配经济学与架构决策革新 2026 生产新范式
1. 动态算力按需计费：简单问题（日常问答）仅需几百毫秒完成快思考；高难度挑战（复杂算法设计、数理证明）允许其思考几分钟，消耗万级 Token。
2. 突破数据墙封锁：不再受限于人类已经写出的书本，模型在规则清晰的数理空间内通过自我博弈（Self-Play）不断产生合成高质量推理轨迹。
3. 架构师权衡转移：从过去“一味追求更大参数量”，转向“中小尺寸优秀 Base 模型 + 充沛的推理时思考算力（Test-Time Compute）”。
