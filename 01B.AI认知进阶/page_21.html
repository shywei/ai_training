CHAPTER 05 · 物理边界、架构反哺与全栈选型

架构师的技术栈选型全景矩阵

在公有云 API、端侧本地量化与私有化机房微调之间，架构师需要从数据合规、SLA 保证、成本曲线与算力规模五大维度建立科学决策树。
路线 A · 云端优先 Public Cloud API
公有云商用 API 服务
• 代表选型：OpenAI, DeepSeek API, 智谱 GLM, 阿里通义千问。
• 核心优势：零机房硬件运维负担，顶尖旗舰模型开箱即用，按需付费，弹性无上限。
考量重点：数据出域合规风险；日调用量突破千万级时，按 Token 线性计费的总拥有成本（TCO）会急剧攀升；易受公网抖动与厂商 Rate Limit 限流影响。
路线 B · 单兵轻量 Local & Edge Quantized
端侧与单机本地量化运行
• 代表选型：Ollama, llama.cpp, vLLM 单卡 (RTX 4090 / Mac M系列)。
• 核心优势：100% 物理离线不出域，零云端调用费用，单兵开发、本地 Code Review 与离线内网系统的极致神器。
考量重点：受限于单机物理显存（主跑 7B~32B INT4）；无法支撑几十上百人高并发生产访问；长上下文吞吐有限。
路线 C · 企业级私有化 On-Premises Dedicated Cluster
私有算力集群自建与模型微调
• 代表选型：vLLM 集群 / Ray / SGLang + 专用服务器（A800/H800/4090集群）。
• 核心优势：军工/金融级绝对数据合规；独占毫秒级 SLA 算力池；高并发下长期平均 Token 成本降至云端 1/10；支持企业专属 SFT。
考量重点：前期重资产硬件采购成本高昂；需要具备 GPU 驱动、RoCE/IB 网络互联与模型运维能力的专业 AI 基础设施工程师。
五维科学决策树速查法则
1. 数据涉密敏感度
• 绝密/金融核心 ➔ 路线 C / B
• 一般通用脱敏业务 ➔ 路线 A
2. 业务响应 SLA
• 强 SLA / 严禁限流 ➔ 路线 C
• 容忍微抖动 ➔ 路线 A
3. 长期并发与调用量
• 峰值持续高并发 ➔ 路线 C
• 波动低频或冷启动 ➔ 路线 A
4. 任务智力复杂度
• 超前沿多模态/慢思考 ➔ 路线 A
• 垂类专用明确任务 ➔ 路线 C / B
5. 团队工程与运维人效
• 研发专注上层应用 ➔ 路线 A
• 具备 GPU 底座运维团队 ➔ 路线 C
