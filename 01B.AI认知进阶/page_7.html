CHAPTER 02 · 模型推理核心机理

Self-Attention 矩阵计算工程与注意力变体演进

自注意力机制是 Transformer 的动态寻址引擎，而从 MHA 到 GQA 的演进则是为了化解长文本推理显存危机的工程妥协典范。
核心公式 缩放点积注意力（Scaled Dot-Product Attention）矩阵乘法
Attention(Q, K, V) = Softmax(Q Kᵀ / √dₖ) V
1. QKᵀ 动态语义点积关联：
Query（当前字探针）与 Key（上下文词索引）做全量点积，计算每一个 Token 对历史上所有 Token 的关联强度打分矩阵。
2. 为什么必须除以 √dₖ 缩放？
若 $d_k=128$，两独立向量点积方差高达 128！极大的数值送入 Softmax 会导致概率极端陡峭、梯度严重弥散为 0，除以 $\sqrt{d_k}$ 强制将方差拉回 1.0。
3. 乘以 V 矩阵加权求和：
Softmax 归一化后的注意力权重矩阵，与 Value（实际语义表征）相乘，完成上下文信息的高维聚合与特征重构。
注意力变体架构演进：从 MHA 到 MQA 与 GQA
1. MHA (Multi-Head) 经典初代
GPT-3 / LLaMA-1 时代标配
每个 Query 头对应独立的 Key 头与 Value 头（如 32 个 Q 对应 32 个 K 和 32 个 V）。
代价：KV Cache 显存与访存带宽随头数线性膨胀，长文本推理时显存迅速爆满。
2. MQA (Multi-Query) 激进精简
PaLM / StarCoder 尝试
所有 Query 头共同共享唯一的一组 Key 头和 Value 头（32 个 Q 对应 1 个 K 和 1 个 V）。
收益与代价：KV 显存暴降 32 倍，吞吐极高；但复杂逻辑表征能力略有损耗。
3. GQA (Grouped-Query) 现代黄金标准
LLaMA-3 / Qwen / Mistral 标配
将 Query 头按组划分（如 32 个 Q 头分成 8 组，每组 4 个 Q 头共享 1 对 KV 头，比例 4:1 或 8:1）。
最佳平衡：在保留多头丰富表达力（几乎零精度损失）的同时，KV 显存削减 75%~87.5%！
