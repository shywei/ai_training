CHAPTER 03

状态机 vs 纯 ReAct — 对比

纯 ReAct（第七课）
LLM 自主决定 THINK→ACT→OBSERVE，没有外部约束
没有停止条件，可能无限循环
工具失败直接报错，无重试无降级
高风险操作无拦截，LLM 直接执行
无执行记录，出错无法回溯
适合：原型验证、Demo、个人工具
不适合：企业生产环境
状态机 + Agent Runtime（第八课）
Runtime 控制循环，最大 10 轮强制停止
每个状态有明确的转换条件，行为可预测
工具失败 → 重试 3 次 → 熔断 → 降级
高风险操作暂停，等待用户确认
每步记录 Trace，可回溯可审计
LLM 仍然是"大脑"
状态机不替代推理能力，而是约束行为边界。
LLM 负责"想"，Runtime 负责"管"。
