🚀 生产 Durable Execution 完整演进架构 分布式高可用
① 三层状态解耦与节点级 Checkpoint 快照
区分 Chat History（对话）、Agent State（会话状态）与 Execution Checkpointer（可恢复任务检查点）。
② 执行步骤与副作用持久化（Replay 重放）
记录已执行步骤与 Tool 回执，故障重放时直接跳过已完成步骤，杜绝重复调用外部副作用。
③ 外部工具幂等控制与长任务挂起唤醒
配合唯一幂等键与 Saga 补偿，任务在 HITL 人工审批期间可休眠数小时/数天后安全唤醒。
④ 跨进程故障恢复（Process Rehydration）
Pod 漂移或发布重启时，异地进程从 Checkpoint 反序列化复水，无损接力剩余流程。
★ 特点：快照持久化 + 执行重放 + 副作用幂等控制，构建生产级确定性底座。
架构分工：Runtime 是操作系统内核调度器，控制状态流转与容错；大模型是认知推理单元，绝不可直接越权自管执行。
Durable Execution：快照持久化 + 执行重放 + 副作用幂等
