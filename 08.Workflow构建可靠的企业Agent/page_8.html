CHAPTER 04

Agent Runtime — 完整执行流程

① 用户请求进入
创建 Trace → 构建 context（画像+记忆+RAG）
↓
② TaskPlanner 规划（可选）
复杂任务 → LLM 拆步骤；简单任务 → 跳过
↓
③ ReAct 循环（最多 10 轮）
THINK → ACT → OBSERVE → 完成? 未完成继续
↓
④ 输出最终回复
脱敏 → 保存记忆 → 返回用户
循环中的异常处理
工具调用失败
ErrorRecovery 介入 → 重试/熔断/降级
高风险操作
ConfirmationService 拦截 → 暂停 → 等待确认
达到最大循环次数
强制让 LLM 基于已有信息总结回复
核心思想
Runtime 是 Agent 的"操作系统"——管理资源、调度任务、处理异常。
LLM 是"CPU"——负责推理，但不能直接管理自己。
