CHAPTER 04

THINK → ACT → OBSERVE — 循环细节

实际执行例子
用户："帮我对比拯救者和 MacBook 的价格"
THINK 1："需要查拯救者价格"
ACT 1：TOOL_CALL:search_knowledge(拯救者笔记本)
OBSERVE 1：拯救者 Y9000P ¥8999, i7/16GB/512GB

THINK 2："还需要查 MacBook"
ACT 2：TOOL_CALL:search_knowledge(MacBook Pro)
OBSERVE 2：MacBook Pro 14 ¥14999, M3/18GB/512GB

THINK 3："信息足够，直接回答"
最终回复："拯救者 ¥8999 更便宜..."
LLM 如何表达"我要调工具"
Prompt 约定输出格式：TOOL_CALL:工具名(参数)
AgentRuntime 用正则提取，路由到对应 MCP Client。
为什么不用原生 Function Calling？
第七课用 FunctionCalling 是黑盒；第八课手搓用文本协议是白盒，THINK/ACT/OBSERVE 全部可见。生产可替换为原生 Function Calling。
AgentRuntime.java — 循环核心
while (iteration < MAX_ITERATIONS) {
  iteration++;

  // THINK
  String thinking = callLLM(thinkPrompt, model);
  String toolCall = extractToolCall(thinking);

  if (toolCall != null) {
    // ACT
    String result = executeToolCall(toolCall);
    // OBSERVE
    conversationHistory.append(result);
  } else {
    // 直接回答
    finalAnswer.append(thinking);
    break;
  }
}
