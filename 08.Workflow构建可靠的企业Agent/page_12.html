CHAPTER 04

模型路由与 Workflow 编排

Router 节点 — Workflow 中的路由
在 Workflow 中，不是所有步骤都用同一个模型。Router 节点根据任务类型，动态选择最合适的模型：简单任务用快模型（便宜、低延迟），复杂任务用推理模型（强、贵）。
动态模型选择（生产建议架构）
TaskPlanner 规划 → reasoning 模型（需要理解任务、拆步骤）
THINK 思考 → reasoning 模型（需要推理、决定下一步）
最终回复 → chat 模型（生成自然语言，不需要强推理）
⚠️ Demo 实际采用统一模型：Demo 为了简化部署，TaskPlanner 和 THINK 都用同一个 reasoning 模型（Qwen3-8B），最终回复也用同一个模型。分级模型路由标注为"生产建议架构"。
Workflow 编排 — 两种模式
① 顺序编排（Demo 采用）
步骤按顺序执行：Plan → Step1 → Step2 → Done
适合：多步查询、对比分析。简单可控，但不能并行。
② 条件编排（仅 PPT 讲解）
根据条件走不同分支：if 库存>0 → 下单，else → 预订
适合：复杂业务流程、审批流。需要 Workflow Engine。
Demo vs 生产
Demo 已覆盖：顺序编排 + 统一模型
仅 PPT 讲解：条件编排、并行编排、分级模型路由
