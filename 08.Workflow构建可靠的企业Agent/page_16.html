CHAPTER 06

可观测性 — Agent 的执行不是黑盒

TraceService — 执行追踪
记录 Agent 每一步的完整执行链路：思考内容、工具调用、入参出参、耗时、重试次数。Tracing 是调试、审计、优化的基础。
Trace 输出示例
Trace #trace-a1b2c3 (总耗时 4.2s)
├─ Plan: 3 步 (0.8s)
├─ Step 1: search_knowledge("拯救者") → 成功 (1.1s)
├─ Step 2: search_knowledge("MacBook") → 成功 (0.9s)
├─ Step 3: LLM 综合分析 → 完成 (1.4s)
└─ Status: COMPLETED
API 端点
GET /api/agent/workflow/status?traceId=xxx
GET /api/agent/workflow/trace?traceId=xxx
GET /api/agent/workflow/traces
Tracing 的四个价值
调试：哪一步出了问题？工具返回了什么？
审计：谁在什么时间做了什么操作？
优化：哪一步最慢？瓶颈在哪？
回放：出了 bug 可以完整复现。
