CHAPTER 01

为什么需要 Workflow

✓ LLM 路由
快模型判断意图：KNOWLEDGE / TOOL / CHAT
✓ Function Calling
LLM 自主决定调用哪个 Tool，MCP 协议统一数据访问
✓ MCP 统一架构
agent-runtime 不直接访问任何数据库，全部走 MCP 协议
✓ context 完整形态
画像 + 记忆 + 对话历史 + RAG + Tool 结果
但 Agent 还是一问一答
"帮我对比拯救者和 MacBook 的价格"
→ LLM 一次只能调一个 Tool，无法分步查两次

"帮我下单"
→ LLM 直接调用下单 Tool，没有人工确认

Tool 调用超时了
→ 直接报错，没有重试，没有降级

Agent 做了什么？
→ 看不到执行过程，无法调试
第八课目标
多步编排 · 人工确认 · 容错重试 · 执行追踪
