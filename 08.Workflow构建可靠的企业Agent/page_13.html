CHAPTER 05

容错设计 — 生产环境的底线

三级容错策略
① 重试（Retry）
最多重试 3 次，指数退避 1s → 2s → 4s。
适用：网络超时、MCP Server 暂时不可用。
原理：大多数临时故障在几秒后会恢复。
② 熔断（Circuit Breaker）
同一工具连续失败 5 次 → 熔断，60 秒内不再调用。
适用：下游服务宕机。
原理：继续重试只会加重下游负担。
③ 降级（Graceful Degradation）
熔断后跳过工具，LLM 基于已有 context 回答。
有回答总比报错好。
实际执行例子
场景：MCP Server 临时超时
第 1 次 调用 → 超时
等待 1s...
第 2 次 调用 → 超时
等待 2s...
第 3 次 调用 → 成功！
场景：MCP Server 宕机
连续 5 次失败 → 熔断触发
60 秒内 跳过该工具
降级 → LLM 基于已有知识回答
