CHAPTER 04

TaskPlanner — LLM 任务规划器

复杂任务自动拆步骤
用户："帮我对比拯救者和 MacBook 的价格，预算 8000"
TaskPlanner 输出：
Step 1: 搜索拯救者笔记本价格和库存
Step 2: 搜索 MacBook 价格和库存
Step 3: 对比分析，结合预算推荐
什么时候需要规划
对比 比较 帮我选 推荐几个 然后 同时
包含多个商品名（≥2）也会触发规划。简单问候、单次查询 → 不规划，直接走 ReAct 循环。
Agent 和 Chatbot 的本质区别：
Chatbot 是用户问一句，LLM 答一句。
Agent 是用户说一个目标，LLM 规划步骤，逐步执行。
TaskPlanner.java — 核心逻辑
public List<WorkflowStep> plan(String msg, String ctx) {
  String prompt = """
    将用户请求分解为可执行步骤。
    用户请求：%s
    输出 JSON 数组：
    [{"step":1,"action":"..."}]
    """.formatted(msg);

  String result = callLLM(prompt, reasoningModel);
  return parseSteps(result);
}
