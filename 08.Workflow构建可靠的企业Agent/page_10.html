TaskPlanner — 认知/概率型规划与确定性 FSM 约束架构

学术定位：大模型的认知/概率型规划
输入："帮我对比拯救者和 MacBook 的价格，预算 8000"
TaskPlanner 输出结构化任务清单（Demo 线性步骤）：
Step 1: 搜索拯救者笔记本价格与库存
Step 2: 搜索 MacBook 价格与库存
Step 3: 聚合比对两款配置，结合预算推荐
⚠️ 概率型规划的天然缺陷（不可盲目信任）
大模型生成规划属于概率采样（Probabilistic Planning），输出不可避免存在不确定性：步骤成环死锁、因果顺序颠倒、前置条件遗漏或幻觉出不存在的工具。
触发机制选型（确定性控制流）
• 触发快路径：命中关键词（对比/比较/帮我选/分析）或商品数 ≥2 触发规划
• 生产演进：规则快路径 + 快模型语义分类兜底，避免单步问候白花规划成本
工程解法：确定性有限状态机（FSM）拓扑约束
🛡️ 规划收敛两道程序防火墙（Demo 清单 vs 生产 DAG）
1. 结构化前置校验：Demo 程序校验子任务步骤合法性与白名单工具；生产演进扩展为 DAG 有向无环性与依赖拓扑排序。
2. 注入受控状态机：校验通过后交由 FSM 强状态流推进；一旦模型输出格式崩溃或校验失败，安全降级为单步直接执行。
TaskPlanner.java 核心骨架
public List<WorkflowStep> plan(String msg, String ctx) {
  String prompt = """
    将用户请求拆解为可执行步骤。
    用户请求：%s
    输出 JSON 数组：[{"step":1,"action":"...","dependencies":[]}]
    """.formatted(msg);
  String result = callLLM(prompt, reasoningModel);
  List<WorkflowStep> steps = parseSteps(result);
  // 确定性程序校验：Demo 清单合法性校验（生产扩展为 DAG 拓扑校验）
  return validateSteps(steps) ? steps : Collections.emptyList();
}
本质收敛：概率规划生成结构化清单，确定性 FSM 校验执行。规划失败安全降级为单步执行，保证业务流永不断死。
