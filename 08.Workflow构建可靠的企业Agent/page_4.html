CHAPTER 02

为什么不能相信 LLM

ReAct 的致命缺陷
❌ 不确定性
同样的输入，LLM 可能走不同的路径。今天查价格再推荐，明天可能直接推荐。你没法写单元测试。
❌ 不可控
LLM 可能跳过步骤、重复调用、调错工具。你没法保证它"照做"。
❌ 无限循环
ReAct 循环没有停止条件，token 烧完也不停，或陷入死循环反复调同一个工具。
❌ 无审计
出了问题无法回溯推理过程。没有 Trace，无法调试。
企业需要什么
✓ 确定性
同样输入走同样路径，能测试能复现能回归。
✓ 可控
高风险操作必须人工确认，不能让 LLM 自己决定下单退款。
✓ 可靠 + 可观测
工具失败要重试降级，每步有 Trace 可回溯。
解决方案：Workflow
用状态机约束行为边界，用 Runtime 控制循环，用 Tracing 记录一切。LLM 是大脑，Workflow 是操作系统。
