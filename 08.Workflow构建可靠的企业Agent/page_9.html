CHAPTER 04

Agent Runtime — 六大组件

组件职责分工
Scheduler（调度器）
控制 ReAct 循环的启停、最大轮次、超时。Demo: AgentRuntime.java
State Manager（状态管理器）
管理 WorkflowState 转换，确保合法转换。Demo: WorkflowState.java
Tool Executor（工具执行器）
执行工具调用，处理重试和熔断。Demo: executeToolCall() + ErrorRecovery
Memory Manager（记忆管理器）
构建 context、管理对话历史。Demo: MemoryManager.java（复用 v4.0）
Checkpoint（检查点）
保存/恢复执行状态。Demo: 仅 CONFIRMING 暂停，无持久化
Tracing（追踪器）
记录每步执行链路。Demo: TraceService.java
组件协作关系
Scheduler(调度器)
│ 控制循环: while(iter < MAX)
├→ MemoryManager → 构建 context
├→ StateManager → PLANNING→EXECUTING
├→ LLM → THINK
├→ ToolExecutor → ACT
│   ├→ ErrorRecovery → 重试/熔断
│   └→ ConfirmationService → 暂停
├→ OBSERVE → 判断完成?
└→ TraceService → 记录每步
vs 第七课的 ShoppingAgentController
第七课：一次性调用，LLM 决定调什么 → 执行 → 返回
第八课：循环调用，Runtime 控制循环 → 多步 → 追踪 → 确认

关键区别：Runtime 管 LLM，不是 LLM 管自己。
