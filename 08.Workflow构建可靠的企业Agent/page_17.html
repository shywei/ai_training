context 演进 — v5.0 完整形态

context 参数每课都在增长
第四课：context = null
第五课：context = 对话历史 + 用户画像
第六课：+ RAG 检索结果
第七课：+ Tool 调用结果
第八课：+ Agent Runtime 编排（多步 Tool + 规划 + 追踪）
注意：第八课没有新增 context 内容，而是改变了 context 的使用方式——从一次性使用变成多轮循环使用。
