CHAPTER 03

状态机 — 让 Agent 的行为可预测

什么是有限状态机（FSM）
系统在任意时刻只能处于一个状态，状态之间的转换由明确的条件触发。不像 LLM 那样"想到哪算哪"。
WorkflowState — 7 个状态
PLANNING EXECUTING CONFIRMING RETRYING COMPLETED FAILED CANCELLED
关键设计：终态不可转换（COMPLETED/FAILED/CANCELLED 是终点），CONFIRMING 只能由用户操作触发。
状态转换图
PLANNING ─────→ EXECUTING
EXECUTING ──┬──→ COMPLETED
├─────→ CONFIRMING ──→ EXECUTING
├─────→ RETRYING ──→ EXECUTING
└─────→ FAILED
CONFIRMING ──→ CANCELLED
状态机的价值
可测试：每个状态转换可独立测试
可调试：出错时知道 Agent 在哪个状态
可审计：状态变更记录在 Trace 中
