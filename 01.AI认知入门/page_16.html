CHAPTER 04

AI编程革命：从补全到Agent（2021-2026）

辅助补全2021-2023
2021
GitHub Copilot 发布
基于OpenAI Codex，AI第一次进入开发者日常工作流，写代码时自动补全下一行、下一个方法
2023
Cursor 推出
首个AI-first IDE，将AI深度集成到开发环境，支持多文件编辑和对话式编程
对话编程2023-2025
2025.2
Vibe Coding（氛围编程）概念提出
Andrej Karpathy提出：用自然语言描述需求，AI自动生成代码，被《柯林斯词典》评为2025年度词汇
2025
Claude Code / Codex CLI 发布
终端AI编程Agent，能自主规划、执行复杂编程任务，AI从辅助工具进化为自主开发者
自主编程2025-2026
2025.10
Cursor Composer · 多文件协同编辑
首个智能体编程模型，支持跨文件理解和修改。Cursor估值达293亿美元
2026.2
Agentic Engineering（智能体工程）
Karpathy进一步提出：通过AI智能体实现高质量自动化开发，开发者角色彻底转变
2026
GitHub ACP协议发布
AI编程工具走向标准化，不同Agent工具可在GitHub生态内互通运行
开发者角色转变："写代码的人" → "描述意图 + 审查决策的人"。AI不是取代程序员，而是让程序员从"搬砖"升级为"建筑师"。
