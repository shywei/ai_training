CHAPTER 02 · 大模型的诞生与本质祛魅

Transformer 架构奇点（2017）：为什么它打破了一切？

2017 年 Google 论文《Attention Is All You Need》重构了底层计算架构。但必须厘清关键工程本质：训练全并行 vs 推理自回归 Decode 逐 Token 串行。
旧范式：RNN / LSTM 的时间递归死锁
训练与推理双重串行
时间步强依赖：必须先计算完 t-1 时刻的隐状态 h_{t-1}，才能计算 t 时刻。训练时无法跨时间步并行：
for (int t = 1; t <= seq_len; t++) {
  h[t] = tanh(W_x * x[t] + W_h * h[t-1] + b); // 强制单线程依赖
}
// GPU 有数万核心，训练时却被时序循环锁死，算力利用率极低！
双重死穴：集群吞吐上限被锁死；文本超过数百词后梯度弥散，长程记忆严重遗忘。
新纪元：Transformer 自注意力机制
空间注意力矩阵
空间全连接替换时间循环：任意两词跳跃距离为 1，将序列转化为高维张量密集乘法：
Attention(Q, K, V) = softmax(Q · K^T / √d_k) · V
// 训练阶段：因果掩码遮盖未来，整篇文章成千上万 Token 一次性 GEMM 并行！
// 推理阶段：前缀已固定，但生成新词仍需依序逐 Token 自回归 Decode！
工程飞跃：训练吞吐量打满万卡 GPU 集群，直接引爆千亿参数预训练模型大爆发！
架构师深度辨析：训练全并行（Training Parallelism）vs 推理自回归（Inference Decode）
1. 训练阶段 · 计算密集型（Compute-Bound 全并行）：
语料目标全部已知。利用 Causal Masking 矩阵遮蔽，所有 Token 的注意力与损失反向传播在多卡集群上100% 全并行计算，彻底喂饱 GPU Tensor Core！
2. 推理阶段 · 访存带宽受限（Memory-Bound 逐字串行）：
自回归模型必须逐 Token 生成（算完词 t 才能作为输入预测词 t+1）。推理无法在时间轴并行，导致每吐一个字都要从显存搬运全部权重，因此需要引入 KV Cache 换取性能！
硬件共振法则：Transformer 最大的胜利并非生物学拟真，而是“放弃递归以迎合 GPU 并行矩阵计算”。看清训练全并行与推理逐字串行的工程权衡，是理解后续大模型部署调度优化的关键基石。
