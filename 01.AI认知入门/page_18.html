通用 Agent 产品生态
Coding Agent之外，一批通用Agent平台正在崛起——它们不只写代码，而是连接一切工具执行任意任务。
产品 厂商 核心定位 关键能力
OpenClaw
 开源社区 开源AI Agent框架，35万+ GitHub Stars 连接50+平台（微信、Telegram、Discord等），自动执行任务、管理日程、代码部署，支持私有化
Coze
 字节跳动 低代码Agent搭建平台 可视化编排工作流，插件市场丰富，一键发布到豆包/飞书/微信
Dify
 开源社区 开源LLM应用开发平台 RAG引擎、Agent编排、API输出，私有化部署，企业级知识库场景首选
Manus
 Butterfly Effect 通用任务执行Agent 端到端完成复杂任务（调研、写报告、做PPT），多Agent协作，云端执行
AutoGLM
 智谱 手机/电脑操控Agent 操作手机App和电脑桌面，模拟人类点击滑动，跨应用自动执行
