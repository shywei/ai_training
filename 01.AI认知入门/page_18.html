CHAPTER 04 · 软件工程的范式革命与角色重塑

软件工程的范式革命：迈向 AI 原生编程时代（1.0 → 2.0 → 3.0）

从逐行敲打确定性指令，到数据驱动训练网络权重，再到意图驱动自主闭环，软件工程正在经历七十年来最深刻的三代范式跨越。
Software 1.0
手写代码时代
1950s – 2010s · 人类硬编码
范式本质：人类程序员直接编写每一行 C/Java/Python 语法逻辑。代码是第一公民。
工作流：需求 → 人脑翻译为算法 → 手工敲打 → 编译器检查 → 线上发布。
Rules + Input = Output
// 瓶颈：面对高维复杂现实规则爆炸
Software 2.0
数据驱动时代
2012 – 2022 · 权重优化
范式本质：人类不再手写具体执行逻辑，而是设计神经网络架构与损失函数，由机器在数据中自动搜索权重矩阵。
工作流：定义网络 → 准备标注数据集 → GPU 梯度下降 → 模型打包。
Input + Output = Weights
// 瓶颈：针对单一业务训练专用小模型
Software 3.0
意图驱动时代
2023 – 2026+ · Agent 闭环
范式本质：人类用自然语言与精准规格（Spec）表达目标意图与安全护栏，AI 自主规划、编写代码、驱动工具并在终端闭环验证！
工作流：人类定义意图契约 → Agent 自主实现与自愈 → 架构师终审。
Human Spec + AI Agent = Done
// 代码退化为按需生成的中间态产物
范式革命的真谛：在 Software 1.0 时代，代码是最终交付物；而在 Software 3.0 时代，“解决业务问题的运行系统”才是最终交付物，代码正在退化为由 AI 在运行时动态生成、编译、检验并按需丢弃的“中间计算态”。人类工程师的核心职责，彻底从“写代码”升维为“设计意图并治理执行”。
