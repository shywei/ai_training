CHAPTER 05

企业优化 — 生产环境必须做的四件事

🔍 Hybrid Search
问题：向量检索对型号/SKU 不敏感
方案：向量 + BM25 关键词融合
实现：pgvector + PostgreSQL tsvector
优先级：第2个做
📊 Rerank 精排
问题：向量检索排序不够精确
方案：交叉编码器重新打分
实现：BGE-Reranker 或 Cohere API
优先级：第3个做
📊 RAG Evaluation
问题："为什么检索不到？"没有量化依据
方案：Recall / Precision / Answer Relevancy
实现：评测集 + 自动计算指标
优先级：第4个做
⚡ Cache 缓存
问题：相同问题反复检索+生成
方案：语义缓存（相似问题共用结果）
实现：Redis 存问题 Embedding + 结果
优先级：第1个做（最简单最有效）
生产落地优先级：Cache → Hybrid Search → Rerank → Evaluation
改动最小、效果最明显的先做。每个都可以在现有 Demo 代码上扩展。
