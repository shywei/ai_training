## Slide Objective
开场定调：从"记住用户"进入"让 Agent 懂商品"。

## Suggested Presentation
上节课让导购 Agent 记住了用户，但它还是个"文盲"——用户问"有什么推荐的笔记本"，它答不上来。因为它根本不知道公司卖什么。

今天的主题是 Knowledge——企业知识系统。课程名称不叫"RAG"，叫"Knowledge"。RAG 只是实现方式，Knowledge 是能力本质。

这节课结束后，导购 Agent 能查商品信息了。但它还不能查库存、不能下单——它只能"说"，不能"做"。"做"是下节课 Tool 的事。

## Key Emphasis
不要一上来就讲 RAG 技术栈。先建立认知：企业 AI 应用必须有知识系统，Prompt 装不下企业知识，Fine-tuning 不划算。
