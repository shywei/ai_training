CHAPTER 05 · 流水线全景

完整 10 步企业级 RAG Pipeline — 离线加工与在线服务双链路

📦 离线数据加工链路 (Offline Ingestion Pipeline, 01~05)
STEP 01
数据接入 (Ingestion)
多源采集：MySQL CDC 增量、文档上传、对象存储 S3 监听与 API 抓取。
Demo ✓ JSON 导入
STEP 02
解析清洗 (Parsing)
版面感知解析（Docling / MinerU 保留多栏与表格结构）、OCR 图像提取、去噪清洗。
生产必须版面感知
STEP 03
分块切分 (Chunking)
父子块切分（Parent-Child）、递归语义分块、Anthropic Contextual 篇章背景注入。
Demo ✓ 单商品单Chunk
STEP 04
元数据提取 (Metadata)
抽取文档层级、租户 ID、时间戳、权限标签，生成 JSONB metadata 供后续硬约束。
Demo ✓ 类别/品牌
STEP 05
向量化与索引 (Indexing)
调用 BGE-M3 嵌入 1024 维；构建 pgvector HNSW 向量索引 + PG tsvector BM25 倒排索引。
Demo ✓ pgvector 索引
🔍 在线检索生成链路 (Online Serving Pipeline, 06~10)
STEP 06
查询改写与门控 (Rewrite)
前置意图门控（Demo 白名单）、多轮指代消解、HyDE 假设生成、Multi-Query 扩写。
Demo ✓ 白名单门控
STEP 07
真正混合检索 (Hybrid)
Dense 向量 + Sparse BM25 双路召回 Top-20 $\to$ RRF 融合，辅以 Metadata 过滤。
Demo 单路 $\to$ 生产双路
STEP 08
交叉精排 (Reranking)
Cross-Encoder 模型（bge-reranker-v2-m3）深度打分重排，取高相关 Top-3~5。
生产必备精排
STEP 09 · 核心强化
上下文组装与压缩 (Assemble)
① 去重压缩：剔除跨片段重复文本；
② Token 预算配额：知识(40%)、历史(30%)超限截断；
③ 防“迷失在中间”排序：最强证据置顶首与尾，弱证据放中间；
④ 低置信度拒答兜底：最高相似度 < 0.4 直接拒答防幻觉！
Demo ✓ buildContext()
STEP 10
受控生成与溯源 (Generate)
严格基于证据回答，角标溯源引用（Citation [1]），防注入隔离，RAG 评测闭环。
Demo ✓ 隔离标签约束
🔄 端到端质量反馈闭环： ① 检索评估（Recall@K/MRR/nDCG） $\to$ ② 生成评估（忠实度/相关性） $\to$ ③ 线上 Bad Case 收集回流 $\to$ ④ 索引与切分配置持续优化。
