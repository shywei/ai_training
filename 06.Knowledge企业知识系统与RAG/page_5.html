CHAPTER 01

RAG — 让 AI 自己"查资料"

RAG = Retrieval-Augmented Generation
检索增强生成 — 先查资料，再回答问题
用户提问
"推荐一台写代码的笔记本"
→
检索
从知识库找相关商品
→
组装 Prompt
用户问题 + 检索结果
→
LLM 生成
基于检索结果回答
本质
不是改模型，是改输入。
把企业知识塞进 Prompt 里，让 LLM "看到"后再回答。
知识库在外部，不在模型里。
优势
知识更新 = 更新文档，不需要重新训练
数据不出企业，安全可控
成本低，只付 API 调用费
和 Memory 的区别
Memory 记"人"（用户偏好、历史）
Knowledge 记"事"（商品信息、企业文档）
两者互补，不可替代
