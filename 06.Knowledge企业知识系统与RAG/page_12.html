CHAPTER 04

context 演进 — Agent 能力逐步增强

context 是整个 Agent 的核心参数，每课逐步填充
v1.0（第四课）
context = null
纯 Prompt，没有上下文
每次对话都是陌生人
v2.0（第五课）
用户画像（MySQL）
+ 对话历史（Redis）
Agent 记住用户了
v3.0（第六课）← 现在
用户画像 + 对话历史
+ RAG 检索结果
+ 相关记忆（pgvector）
Agent 能查商品了
v4.0（第七课）
+ Tool 调用结果
Agent 能查库存、下单
从"能说"到"能做"
v3.0 context 的四部分
① 用户画像（MySQL）— 始终查询
② 相关记忆（pgvector）— 始终查询
③ 对话历史（Redis）— 沉淀后为空
④ 参考知识（pgvector）— 关键词过滤后检索
