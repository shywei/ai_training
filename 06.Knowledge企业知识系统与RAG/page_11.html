CHAPTER 03

语义检索 — VectorStoreConfig 与 RetrievalService

语义检索的四步流程
1. 用户问题 → Spring AI EmbeddingModel → 1024维查询向量
2. 查询向量与 vector_store 中的向量计算余弦相似度（Cosine）
3. 过滤低于 similarityThreshold 的噪声结果
4. 返回最相似的 Top-K 个 Document 并格式化
SearchRequest 三个核心旋钮
withTopK(3 / 5)：召回条数（太少漏信息，太多塞噪声）
withSimilarityThreshold(0.3 ~ 0.5)：最低余弦相似度门槛
withFilterExpression(...)：按 JSONB metadata（如 category == '笔记本'）预过滤
纯稠密向量检索的局限
对精确型号/SKU/错误码不够敏感（如搜“NB001”或“X1 Carbon Gen12”可能被泛化语义稀释）
双编码器粗排 Top-K 顺序未必最优 → 生产需配合 Hybrid Search + Rerank
💻 Demo 代码：VectorStoreConfig.java & RetrievalService.java（v1.3）
// 1. VectorStoreConfig.java — 注入 1024 维 PgVectorStore
@Bean
public PgVectorStore pgVectorStore(
    JdbcTemplate pgJdbcTemplate, EmbeddingModel embeddingModel) {
  return PgVectorStore.builder(pgJdbcTemplate, embeddingModel)
      .withDimensions(1024).build();
}

// 2. RetrievalService.java — Spring AI VectorStore 语义检索
public String retrieve(String query, int topK) {
  // ① 关键词过滤拦截闲聊（下一节详解）
  if (!isProductRelated(query)) {
    return null;
  }
  // ② 构建 SearchRequest（Top-K + 相似度阈值 0.3/0.5）
  SearchRequest request = SearchRequest.query(query)
      .withTopK(topK)                   // 默认召回 Top 3~5
      .withSimilarityThreshold(0.3);    // 过滤低相关噪声

  // ③ 执行 pgvector 余弦相似度检索
  List<Document> docs = vectorStore.similaritySearch(request);
  if (docs == null || docs.isEmpty()) return null;

  // ④ 格式化为带编号的参考知识文本
  return formatResults(docs);
}
v1.3 调用链：用户问题 → RetrievalService.retrieve() → PgVectorStore.similaritySearch(SearchRequest) → Top-K Document → 格式化注入 Prompt。
