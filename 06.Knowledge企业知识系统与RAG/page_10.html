CHAPTER 03

语义检索 — 怎么找到相关的知识

语义检索的流程
1. 用户问题 → Embedding → 查询向量
2. 查询向量和知识库中的向量做余弦相似度计算
3. 返回最相似的 Top-K 个结果
4. 相似度阈值过滤（低于阈值的丢弃）
关键参数
Top-K：返回几个结果？Demo 默认 3 个。
相似度阈值：低于多少分的不要？Demo 默认 0.3。
距离度量：用什么算法算相似度？Demo 用 cosine。
语义检索的局限
对专有名词不敏感（"X1 Carbon"可能匹配不到）
需要调优（Chunk Size、Top-K、阈值都会影响效果）
这就是后面要讲 Hybrid Search 的原因
💻 Demo 代码：RetrievalService.java
public String retrieve(String query, int topK) {
  // 1. 关键词过滤（下一节讲）
  if (!isProductRelated(query))
    return null;

  // 2. 构建检索请求
  SearchRequest req = SearchRequest.query(query)
    .withTopK(topK)           // 返回几个
    .withSimilarityThreshold(0.3); // 最低分数

  // 3. 执行向量检索（pgvector cosine）
  List<Document> results =
    vectorStore.similaritySearch(req);

  if (results == null || results.isEmpty())
    return null;

  // 4. 格式化结果
  return formatResults(results);
}
流程：用户问题 → Embedding（Spring AI 自动完成）→ pgvector cosine search → Top-K 结果 → 格式化。
