🚨 多数据源冲突陷阱（VectorStoreConfig.java）
Spring AI 默认会将自动装配的 PgVectorStore 绑定到项目的主数据源。因为本项目的业务主库是 MySQL，如果不做隔离，启动时会因尝试向 MySQL 执行 PG 向量语法而直接崩溃。必须在 VectorStoreConfig.java 中显式定义独立的 PostgreSQL DataSource，并手动构建 PgVectorStore Bean（1024 维）。
💻 Demo 代码：VectorStoreConfig.java（v1.3）
// VectorStoreConfig.java — PostgreSQL 独立数据源
@Bean
public DataSource pgvectorDataSource() {
  HikariDataSource ds = new HikariDataSource();
  ds.setJdbcUrl(pgUrl);  // jdbc:postgresql://localhost:5432/agent_db
  ds.setUsername(pgUser);
  ds.setPassword(pgPass);
  ds.setMaximumPoolSize(5);
  return ds;
}

// 手动组装 Spring AI PgVectorStore Bean（1024 维）
@Bean
public PgVectorStore pgVectorStore(
    JdbcTemplate pgJdbcTemplate, EmbeddingModel embeddingModel) {
  return PgVectorStore.builder(pgJdbcTemplate, embeddingModel)
      .withDimensions(1024)
      .build();
}

// docs/schema-knowledge.sql
CREATE TABLE vector_store (
  id        VARCHAR(255) PRIMARY KEY,
  content   TEXT NOT NULL,
  metadata  JSONB,
  embedding vector(1024) NOT NULL
);
CREATE INDEX idx_vs_embedding ON vector_store
  USING hnsw (embedding vector_cosine_ops);
