CHAPTER 01

技术选型 — Prompt vs RAG vs 微调

三种技术路线的本质区别
① Prompt 工程
改变的是单次推理的行为边界。
定义角色、约束输出格式、注入少量示例。
优点：零成本、即时生效。
局限：能注入的知识量极其有限。
② RAG（知识检索）
改变的是事实与外部知识储备（开卷考试）。
知识可实时更新、支持段落级溯源引用。
优点：灵活、可审计、数据可控。
本课核心内容。
③ 微调（Fine-tuning）
改变的是模型的行为风格与专业术语敏感度。
适合：调整输出格式、行业术语、对话风格。
不适合存业务数据——知识无法实时更新、仍有幻觉、无法做权限过滤。
企业常见问题
"为什么不直接拿企业文档去微调专属模型？"
这是企业立项时管理层最常问的问题。

答案：微调改变的是"怎么说"，不是"知道什么"。

• 微调不能让模型"记住"你的商品价格——价格每天变
• 微调后的模型仍有幻觉——它可能编造不存在的商品
• 微调无法做权限过滤——所有用户看到同样的"知识"
• 微调更新成本极高——每次数据变化都要重新训练
正确的组合方式
Prompt 定义行为边界（你是导购助手，推荐商品时引用配置）
RAG 注入实时知识（商品信息、价格、库存、用户记忆）
微调 优化表达风格（更专业的术语、更自然的对话）

三者互补，不互斥。企业 Agent 通常三者都用。
本课聚焦 RAG：因为它是最适合企业知识管理的技术路线。
微调是"改变模型本身"，RAG 是"给模型配一个图书馆"。
