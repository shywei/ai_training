CHAPTER 01

Prompt 的局限 — 为什么装不下企业知识

一个实际问题
导购 Agent 能聊天、能记住用户。
但用户问"有什么推荐的笔记本？"
它答不上来。为什么？
因为它根本不知道公司卖什么
商品信息存在哪？ERP、商品目录、Wiki。
这些地方的共同特点：大模型都读不到。

System Prompt 有长度限制（几千 token），
不可能把所有商品信息塞进去。
就算塞得下，商品上新了怎么办？改 Prompt？
核心矛盾
大模型的训练数据是公开互联网，
企业知识是内部私有的。
两者之间有一道天然的鸿沟。
Prompt 能做什么、不能做什么
✓ Prompt 能做的
定义角色和行为
设置约束和规则
给几个示例（Few-shot）
控制输出格式
✗ Prompt 做不到的
包含企业所有商品信息
包含内部文档和 FAQ
实时更新（商品上新、价格变动）
处理大量结构化数据
那怎么办？
两个方向：
1. 把知识"烧"进模型（Fine-tuning）→ 下一页讲
2. 让模型自己"查资料"（RAG）→ 本课重点
