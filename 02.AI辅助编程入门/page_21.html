CHAPTER 06 · 上下文退化原理与单兵防坑铁律

优质学习资源、Spec 标准与开源生态推荐

AI 编程工具层出不穷，但底层的协议标准、最佳实践与思维模式是高度相通的。精选 2026 前沿生态资源，助你持续精进：
1. 开放规范与官方标准
• AGENTS.md 规范标准：跨 Cursor、Claude Code、Qoder 的统一项目级指令标准。
• Model Context Protocol (MCP)：Anthropic 开源的智能体统一系统集成协议（modelcontextprotocol.io）。
• OpenSpec / GitHub Spec-Kit：标准化 SDD 规格驱动开发模板与生命周期定义。
2. 顶级社区与规则市场
• Cursor Directory (cursor.directory)：全球最大的企业级 .cursorrules / AGENTS.md 最佳实践库。
• skills.sh 技能市场：一键安装开源 Agent CLI 技能包（涵盖 Git、K8s、SQL、安全审计）。
• Roo Code / Cline 开源社区：在开源透明与细粒度工具执行权限控制领域的先锋阵地。
3. 架构必读权威指南
• Anthropic《Building effective agents》：系统拆解 Workflows 与 Autonomous Agents 的宗师级白皮书。
• OpenAI《Practices for Harnessing Coding LLMs》：官方关于 Token 缓存与代码单测闭环的深度洞见。
• 国内大厂工程实践：阿里 Qoder 仓库级上下文架构演进、腾讯 CodeBuddy Spec 闭环落地报告。
4. 进阶学习路线图
• 普通学员主线（直通 03 课）：学完本课直接迈入《第 03 课：AI Agent架构认知入门》，打通智能体顶层应用架构。
• 进阶深潜支线（02B 可选深潜）：若为项目 Leader/高级开发，可选修《02B. AI辅助编程进阶》，攻坚 SDD 规格驱动与多 Agent 并行。
工具会不断洗牌，但标准与工程方法论永存：不与任何单一工具深度绑定，依托开放标准沉淀团队的规范资产，才能立于不败之地。
