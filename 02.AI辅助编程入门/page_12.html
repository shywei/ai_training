CHAPTER 04 · HARNESS 驾驭层“六件套”详解

支柱 ④ · `Skills`（渐进式按需技能包）原理与生态

为什么不把团队所有 SOP 都塞进 `AGENTS.md`？
一个研发团队往往有 20+ 种专项作业流程（Flyway 数据库迁移、慢 SQL 索引诊断、安全漏洞修复、TDD 垂直切片、PR 审查清单）。如果全部写进 `AGENTS.md`，会话还没开始就白白吞掉 40,000+ Tokens，不仅拖慢推理，还会稀释核心指令注意力！
核心机制：Progressive Disclosure（三级渐进式披露，省下 90% Token！）
Level 1 · 启动常驻层：仅加载 YAML 技能目录（~50 Tokens/每个） 常驻内存极轻量
Agent 启动时只扫描各技能包头部的 `name` 与 `description`（一句话说明该技能干什么、何时触发）。哪怕装了 30 个 Skills，也仅占约 1,500 Tokens！
Level 2 · 任务触发层：按需读取 `SKILL.md` 正文（~1,500 Tokens） 匹配意图时动态挂载
当用户提问“帮我给这张表加个字段并生成 Flyway 脚本”或显式输入 `/flyway-migration` 时，Agent 才调用 `Read` 将对应的 `SKILL.md` 完整 SOP 读入当前上下文。
Level 3 · 脚本与模板执行层：`scripts/` & `templates/`（0 代码 Token 污染） 黑盒执行脚本
按照 `SKILL.md` 指引，Agent 直接调用技能包自带的校验脚本（如 `python scripts/check_ddl.py`）或读取代码模板，脚本源码本身无需塞进大模型上下文！
2026 开放 Skills 生态（一次编写，全 Agent 通用）
标准存放路径（各主流工具自动发现）：
· Claude Code / 通用：.claude/skills/<skill-name>/SKILL.md
· Cursor / Antigravity：.agent/skills/<skill-name>/SKILL.md
· OpenCode / Qoder：.opencode/skills/<skill-name>/SKILL.md
使用 `skills.sh` 一键安装社区顶尖技能包：
# 安装 Anthropic 官方技能集
$ npx skills add anthropics/skills --skill mcp-builder
# 安装 TDD 垂直切片测试驱动开发技能
$ npx skills add mattpocock/skills --skill tdd
对企业研发团队的核心价值：知识资产代码化
过去团队 Wiki 里的《接口安全自查表》《分库分表接入指南》没人看；现在将其封装成仓库里的 `skills/`，**资深架构师写好一套 Skill，全组初级开发和实习生的 Agent 瞬间获得同等专家作业水准！**
