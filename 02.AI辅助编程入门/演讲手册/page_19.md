# OpenCode实战：演示场景

## Slide Objective
通过五个真实、典型的开发场景，向学员展示 Agent 强大的自动化解决问题的能力，覆盖从开发到维护的全生命周期。

## Suggested Presentation
在接下来的实操中，我将给大家演示这五个典型的场景。
场景 1，是从无到有开发新功能。我会让 Agent 给现有项目加一个文件上传接口，大家注意看它怎么自动翻看项目，找到合适的目录并生成测试。
场景 2，也是大家最头疼的：修 Bug。给它一段报错日志，看它怎么顺藤摸瓜找到那个导致空指针的代码。
场景 3，代码重构。把面条代码重构为策略模式，而且要求它保持原有功能不变。
场景 4，补单元测试。很多人讨厌写测试，我们看看交给 AI 怎么做。
场景 5，代码理解。当你接手一个祖传项目，如何让 Agent 在三分钟内帮你画出调用关系图。
（讲师可以根据时间，选择 2-3 个核心场景进行现场实操演示）

## Key Emphasis
强调每个场景的“观察点”（Agent 是如何思考和行动的），引导学员不仅看结果，更要看过程。
强调这五个场景覆盖了日常开发的 80% 痛点。

## Optional Extension
如果现场演示翻车了（比如 Agent 生成了错误的代码），这是绝佳的教学机会！讲师应该立刻向学员展示：“大家看，AI 犯错了。这时候我们该怎么通过修正提示词或补充上下文，让它回到正轨。”

## Classroom Interaction
这五个场景，大家平时最头疼、最想让 AI 代替你做的是哪一个？（根据多数人的选择优先演示）

## Take Away
Agent 能够深入参与新功能开发、排障、重构、测试及代码审查等所有核心研发环节。

## Why This Slide Matters
将抽象的 Agent 能力具象化，让学员切实感受到 AI 工具对日常工作的颠覆性提升。

## Transition
大家看完演示，是不是觉得很神奇？但在你们自己回去操作的时候，很可能效果没这么好。为什么？因为使用 Agent 是有技巧的。我为大家总结了 5 个核心技巧。
