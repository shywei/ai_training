# 提示词工程：进阶与编程场景

## Slide Objective
将提示词理论落地到具体的开发场景中，并引出 Agent 框架底层常用的进阶提示词概念。

## Suggested Presentation
我们来看看真实编程场景下，提示词长什么样。
比如代码审查，不要只说“审查代码”，你得列出审查的重点：线程安全、空指针风险、异常处理。比如重构，你得明确告诉它要重构成什么设计模式，约束条件是什么。
这三个例子大家课后可以直接抄去用。
但这里我更想强调右边的“进阶技巧”。这些技巧不是让我们手动敲的，而是 Agent 工具在底层帮我们做的。
比如 System Prompt（系统提示词），IDE 工具会默认在后台告诉大模型：“你是一个强大的编程助手，必须遵守代码规范”。
比如 ReAct 模式，就是让模型一边思考一边行动，这是 Agent 能自主干活的核心机制。
所以大家看，提示词工程的终点，其实不是让你每天去背话术，而是将这些优秀的提示词模式，固化到系统和工具中。

## Key Emphasis
展示编程场景提示词的“结构化”特征。
重点解释 System Prompt 和 ReAct 模式，为下一章讲解 Harness 体系打下概念基础。不需要展开讲解算法细节。

## Optional Extension
如果学员问什么是“自洽性（Self-Consistency）”，可以举例：就像让 3 个 AI 独立做一道题，然后投票选出多数人赞同的答案，以此提高正确率。
