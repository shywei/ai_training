## Suggested Presentation
请看第 20 页，这是无数工程师用成千上万 Token 账单和通宵排障换来的血泪经验：单兵日常高效交互五条铁律！
1. **Plan Mode 先行**：面对超过 2 个文件的改动，强制开启 Plan 只读规划模式！让 Agent 先出思路和 Task List，人类花 1 分钟确认架构无误后再授权写代码。想透再动刀，拒绝盲目乱改；
2. **@ 精准喂料**：用 `@File`、`@Symbol` 精确锚定上下文。严禁大包大揽让模型全盘盲搜；
3. **频繁快照，小步提交**：每跑通一个单测或函数，立刻 `git commit`。一旦发现 Agent 改飞了，**一秒钟不要犹豫，立刻 `git reset --hard HEAD`**！彻底止损，绝不纠缠！
4. **十五轮法则**：聊到第 15 轮任务仍未完成，果断执行 `/compact`，或者让它总结当前结论，直接开一个全新的干净 Session 继续！清空历史错误累积；
5. **临时脚本开路**：面对批量重构或复杂数据检查，命令它在 `scratch/` 目录先写个独立 Python/Shell 脚本本地验证，跑通后再合并入代码库。
**牢记口诀：先想后动刀，精准喂材料；小步常提交，十五轮就跑，脚本先验好！**

## Key Q&A / Clarifications
**Q：如果在执行 git reset --hard 之前有自己手写的修改怎么办？**
A：养成习惯：进入 AI Agent 自动化流程前，保证工作区 clean 或使用 `git stash`；更好的做法是在下节课（02B）将要学习的 `git worktree` 独立隔离分支中运行 Agent。
