# AI辅助编程的七个阶段

## Slide Objective
梳理 AI 辅助编程的发展演进路线，让学员知道技术是如何从简单的 Prompt 一步步演化到 Multi-Agent，帮助建立关于 Agent 发展的宏观认知。

## Suggested Presentation
AI 辅助编程并不是一蹴而就的，它经历了七个关键阶段。
在“对话时代”，我们只有 Prompt，也就是提示词，这是基础中的基础。
但很快，人们发现模型不能只会说，还得会做，于是进入了“工具时代”。我们给 AI 加上了工具（Function Calling），给它提供项目上下文（Context Engineering），甚至给它编排了固定的流水线（Workflow）。这时候，AI 成了一个有手的执行者。
可是，流程是人定的，不够灵活。于是我们进入了现在的“自主时代”。Single Agent 出现了，它能自己规划任务、自己调度工具；随后更进化出了 Agentic Loop，它能写完代码自己跑测试，报错了自己修，形成迭代闭环。
而今天最前沿的，是“协作时代”。主 Agent 会派生出多个子 Agent 并行处理任务，就像一个开发团队一样。
大家看这七个阶段，这不是未来的想象，而是已经发生的现实。我们今天要讲的工具，它们其实就处在阶段 5、6、7 的位置。

## Key Emphasis
解释从“对话”到“工具”再到“自主”的核心演变逻辑。
重点说明：Prompt 依然是所有阶段的基础。后面的工具和自主能力，是建立在基础能力之上的。无需详细解释每个英文名词的底层代码实现。

## Optional Extension
如果学员问为什么没有列出具体的年代时间，可以说明：因为技术发展太快，这七个阶段几乎是在短短两三年内迅速重叠演进的。

## Classroom Interaction
大家觉得，你们现在的日常开发，停留在第几个阶段？是还在靠提示词（阶段1），还是已经用上了多智能体协作（阶段7）？

## Take Away
AI 编程的进化方向，就是从被动执行指令，走向自主规划与闭环迭代。

## Why This Slide Matters
没有这页，学员对 Agent 的理解会很孤立。这页提供了一个坐标系，让学员知道今天的技术处于什么段位，以及为什么需要学习 harness 和工具链。

## Transition
大家注意看，从阶段1到阶段7，AI 能处理的任务越来越复杂。但决定它到底能处理多复杂的任务，有一个物理瓶颈，那就是它一次能“看”多少东西。这就是我们接下来要讲的：Token 机制。
