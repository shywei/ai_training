## Suggested Presentation
各位开发团队的架构师与工程师，大家好！欢迎来到第 02 课：《AI 辅助编程入门：2026 工具全景与 Harness 底座》。
在第 01 课中，我们已经系统重塑了 AI 认知，拆解了大模型的自回归原理与预训练依赖库本质。大家已经知道，模型本身是个纯概率的文字预测机，它不能直接连终端、跑单测。
那么在今天这节课，我们要解决的核心问题就是：作为一名一线开发者，如何把大模型变成我们手边最强大的“全自主编程智能体（Coding Agent）”？
我们将彻底告别 2023 年把代码复制粘贴到网页聊天框的“人肉中继”原始阶段；掌握 2026 最前沿的 AI-Native IDE、终端 CLI 与四大产品阵营；吃透 Token 缓存与 Prefix Caching 极度省钱的心法；并重点剖析驾驭大模型的“Harness 六件套（AGENTS.md、Hooks、Skills、MCP、Subagents）”。
让我们正式开始！

## Key Q&A / Clarifications
**Q：第 02 课和 02B 课的分工定位是什么？**
A：第 02 课是面向全体普通学员的必修课，聚焦“单兵上手与核心工程底座”——工具怎么选、Prompt 怎么写、Harness 六件套如何配置、上下文退化如何防坑，全面实现单兵提效，为后续课程打好坚实基础；而 02B 是一门可以跳过的选修/进阶课程，专为项目 Leader 和高级开发深入学习企业级规格驱动（SDD）、EARS 规范、存量老代码重构与 Git Worktree 多 Agent 并行流。普通学员学完第 02 课后，标准路线是直接进入《第 03 课：AI Agent架构认知入门》！
