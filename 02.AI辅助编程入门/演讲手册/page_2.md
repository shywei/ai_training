## Suggested Presentation
请看第 02 课的课程目录。本课共由六大章节构成：
第一章【从网页对话到 Agent 编程】：直面人肉总线的效率天花板，看懂 2021~2026 AI 编程四代演进路线；
第二章【Token、缓存与编程模型选型】：讲清 BPE 词元、Prefix Caching（前缀缓存能省 75%~90% 成本）以及“Plan 慢思考 + Act 快执行”的双模组合拳；
第三章【面向 Coding Agent 的提示词工程】：彻底淘汰套话，掌握锚点、契约、负面红线与验证命令四大确定性要素；
第四章【Harness 驾驭层六件套详解】：全课最核心的重头戏！系统拆解 AGENTS.md、Hooks 确定性护栏、Skills 渐进披露、MCP 与 Subagents 上下文隔离；
第五章【2026 主流 Coding Agent 四大阵营与选型】：全面横评 Cursor、Antigravity、阿里 Qoder、腾讯 CodeBuddy、Claude Code 与开源插件，给出团队选型决策树与 CLI 实操；

## Key Q&A / Clarifications
**Q：学习本课需要提前装好所有工具吗？**
A：不需要。掌握底层原理和标准（如 AGENTS.md、Hooks）后，你在任何工具上都能一通百通。课后可根据推荐选型安装一款自己最顺手的即可。
