CHAPTER 05 · 2026 主流 CODING AGENT 四大阵营与选型

Terminal Coding Agent 快速上手与三种工作模式

1. 30 秒极速安装（以 Claude Code 与开源 OpenCode 为例）
# 1. 安装 Claude Code（官方原生二进制安装）或 OpenCode（开源多模型）
$ curl -fsSL https://claude.ai/install.sh | bash  # 或 npm i -g opencode-ai
# 2. 进入你的项目根目录直接启动！
$ cd /workspace/order-service && claude         # 或运行 opencode
2. 高频必背的 6 大斜杠命令（Slash Commands）
/init
新项目第一条命令！自动扫描仓库构建工具、目录架构与代码风格，生成初始 `AGENTS.md` / `CLAUDE.md`。
/plan (Shift+Tab)
切换至只读规划模式（Plan Mode）：先分析代码输出修改计划，未经人类批准绝不修改任何文件。
/compact
上下文瘦身神器！将前序冗长的排查对话压缩为精炼摘要，释放 80% 窗口空间并保留核心记忆。
/clear
彻底清空当前会话历史。做完一个独立需求切换到下一个任务时必敲，防止旧任务干扰。
/review
对当前未提交的 `git diff` 或指定 PR 启动深度代码审查（并发安全、空指针、越权漏洞）。
/cost · /context
实时透视当前会话消耗了多少 Token、Prefix Cache 命中率多少、哪些 MCP/文件占用了窗口。
3. Terminal Agent 的三大实战运行形态
形态 ① · 沉浸式终端交互模式（Interactive TUI） 架构设计 & 大手术
在独立终端全屏启动 `claude` 或 `opencode`：支持 `@` 模糊搜索文件、`!mvn test` 直接内联跑命令、粘贴报错截图，适合处理跨 10+ 个文件的深度需求与疑难杂症排障。
形态 ② · IDE 伴生联动模式（IDE Companion） IDEA / VS Code 黄金搭档
在 IntelliJ IDEA 或 VS Code 内置终端里启动 Terminal Agent：**你在编辑器里用鼠标高亮选中的代码行、当前打开的 Tab、以及 IDE 语法红线（LSP Diagnostics）会自动实时同步给终端里的 Agent**，改完代码直接在 IDE 高亮视图里可视化审查 Diff！
形态 ③ · 无头管道与批处理模式（Headless & Unix Pipe） 脚本化 & CI/CD 神器
把大模型当成标准 Unix 命令行过滤器，直接与管道 `|` 和 Shell 脚本结合：
# 管道直接分析线上错误日志并输出根因报告
$ tail -n 200 error.log | claude -p "定位 NPE 根因并给出修复补丁"
# 开源 OpenCode 非交互执行单测补齐任务
$ opencode run "为 PaymentService 补齐边界单测并跑通 mvn test"
