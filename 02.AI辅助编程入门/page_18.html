CHAPTER 07 · 演示场景

OpenCode实战：安装与配置

安装步骤
1
安装OpenCode
开源免费的终端AI编程Agent，Go语言编写，单二进制无依赖
curl -fsSL https://opencode.ai/install | bash
# 或 go install github.com/anomalyco/opencode@latest
2
配置模型API Key
支持75+模型，配置任意一个即可。推荐DeepSeek V4（便宜好用）或Claude（最强编程）
export ANTHROPIC_API_KEY=sk-xxx
# 或 export DEEPSEEK_API_KEY=sk-xxx
3
进入项目目录，启动OpenCode
在你的项目根目录下启动，Agent会自动读取项目结构
cd my-spring-project
opencode
Windows用户：推荐WSL
OpenCode官方推荐在WSL中运行，文件性能更好、终端兼容性更佳：
① 管理员PowerShell：wsl --install → 重启
② WSL终端中安装：按上方步骤安装OpenCode
③ 访问Windows文件：cd /mnt/c/Users/你的用户名/project
④ 配合VS Code的WSL扩展，打造一体化开发体验
三种使用方式
方式一：TUI（终端交互界面）
默认模式，进入交互式终端界面，支持对话、审批、快捷键操作。
cd my-project && opencode
# 继续上次会话：opencode --continue
适合日常开发，实时交互，逐个审批Agent操作。
方式二：CLI（命令行模式）
非交互式，执行完直接退出。适合脚本、CI/CD流水线、自动化任务。
opencode run "给UserService添加密码重置功能"
# 指定模型：opencode run -m deepseek/chat "解释闭包"
一次性任务、批量处理、集成到构建流程中。
方式三：Web（浏览器界面）
启动本地Web服务器，在浏览器中使用。适合不习惯终端的用户、远程访问、团队共享。
opencode web
# 指定端口：opencode web --port 4096
# 网络访问：opencode web --hostname 0.0.0.0
自动打开浏览器，WSL下运行效果最佳。
选型建议
日常开发用TUI · 自动化/CI用CLI · 演示/团队用Web
