产品计费模式（2026年主流）
Coding Plan（按任务包）
按月订阅，含固定任务额度。如Codex Plus $20/月含15-80个任务/5小时窗口。适合用量可预测的开发者。
Token Plan / Credit Plan（按量计费）
2026年4月Codex改为token-based credit计费：简单bug fix约5 credits，大型重构约45 credits。费用与实际消耗直接挂钩。
OpenCode Go（开源免费）
开源终端Agent，Go语言编写，工具本身免费。只需支付所选模型的API费用。配合DeepSeek V4，月成本可低至几十元。
国内厂商也纷纷推出Coding Plan：MiniMax ¥29起、智谱Max ¥469，价格跨度16倍。选型关键：匹配任务复杂度和使用频率。
模型选择策略：便宜模型执行，贵模型规划
代码补全 / 解释 / 翻译
→ 快速模型（Flash/Sonnet）
架构设计 / 复杂重构
→ 推理模型（Opus/R1）
Agent Loop（循环执行）
→ 快速模型执行 + 推理模型规划
不是"什么都用最贵的模型"，而是任务复杂度匹配模型能力。简单任务用贵模型是浪费钱，复杂任务用便宜模型是浪费时间。
