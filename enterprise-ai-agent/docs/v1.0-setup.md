# v1.0-prompt 部署指南

## 外部依赖

v1.0 只需要一个外部服务：**LLM API**（硅基流动，免费）。

## 环境准备

### 1. Java 17+

```bash
java -version
```

### 2. Node.js 16+

```bash
node -v
```

### 3. 获取 API Key

1. 注册 https://siliconflow.cn
2. 控制台 → API Keys → 创建
3. 复制 Key

### 4. 配置 API Key

编辑 `agent-runtime/src/main/resources/application-local.yml`：

```yaml
spring:
  ai:
    openai:
      api-key: sk-你的Key
```

## 启动

### 后端

```bash
cd agent-runtime
./mvnw spring-boot:run
```

### 前端

```bash
cd web
npm install
npm run dev
```

前端启动后访问：**http://localhost:3000**

> dev server 已配置代理，`/api/*` 请求会自动转发到后端 `http://localhost:8080`。

## API 测试

```bash
# 流式对话
curl -N "http://localhost:8080/api/agent/chat?message=帮我推荐一台笔记本"

# 结构化推荐
curl -X POST "http://localhost:8080/api/agent/recommend" \
  -H "Content-Type: text/plain" \
  -d "预算8000，主要写代码"
```
