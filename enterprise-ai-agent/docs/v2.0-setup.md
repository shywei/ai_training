# v2.0-memory 部署指南

## 新增依赖

| 依赖 | 必需 | 说明 |
|------|------|------|
| Redis | ✅ | Session Memory 存储 |
| MySQL | ✅ | 用户画像持久化 |
| MyBatis Plus | ✅ | ORM 框架 |

## 环境准备

### 1. 安装 Redis

```bash
# Docker(推荐)
docker run -d -p 6379:6379 redis:latest

# macOS
brew install redis && brew services start redis
```

### 2. 安装 MySQL

```bash
# Docker(推荐)
docker run -d -p 3306:3306 -e MYSQL_ROOT_PASSWORD=*** -e MYSQL_DATABASE=agent_db mysql:8

# macOS
brew install mysql && brew services start mysql
```

### 3. 建表

执行 `docs/schema.sql` 中的 SQL 脚本:

```sql
-- 用户表
CREATE TABLE IF NOT EXISTS `user` (
    `id`         BIGINT AUTO_INCREMENT PRIMARY KEY,
    `username`   VARCHAR(64)  NOT NULL UNIQUE COMMENT '用户名',
    `password`   VARCHAR(128) NOT NULL COMMENT '密码',
    `display_name` VARCHAR(64) COMMENT '显示名称',
    `created_at` DATETIME     DEFAULT CURRENT_TIMESTAMP,
    INDEX `idx_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- 用户画像表(长期记忆)
CREATE TABLE IF NOT EXISTS user_profile (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id     VARCHAR(64)  NOT NULL UNIQUE COMMENT '用户ID',
    facts       TEXT         COMMENT '事实:姓名、职业等',
    preferences TEXT         COMMENT '偏好:颜色、品牌、预算等',
    tasks       TEXT         COMMENT '任务:当前需求、待办',
    constraints TEXT         COMMENT '约束:禁区、限制',
    updated_at  BIGINT       COMMENT '更新时间戳',
    INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户画像表';

-- 初始用户(方便演示)
INSERT INTO `user` (`username`, `password`, `display_name`) VALUES
('zhangsan', '123456', '张三'),
('lisi', '123456', '李四');
```

### 4. 配置

编辑 `agent-runtime/src/main/resources/application-local.yml`:

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
  datasource:
    url: jdbc:mysql://localhost:3306/agent_db?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: root
```

### 5. 启动

```bash
cd agent-runtime && ./mvnw spring-boot:run
cd web && npm run dev
```

## v2.0 新增 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/auth/login` | POST | 登录(username + password) |
| `/api/auth/register` | POST | 注册(username + password + displayName) |
| `/api/agent/chat?message=xxx&sessionId=xxx&userId=xxx` | GET | 流式对话(注入对话历史 + 用户画像) |
| `/api/agent/memory/save` | POST | 保存对话到 Memory(每 5 轮触发画像抽取) |
| `/api/agent/memory/clear?sessionId=xxx` | POST | 清空 Session |

## 验证方法

### 验证登录
1. 打开 http://localhost:3000，显示登录页
2. 输入 zhangsan / 123456 登录
3. 顶部栏显示 "👤 张三" 和退出按钮

### 验证注册
1. 点击“没有账号？注册”
2. 输入新用户名和密码
3. 注册成功后自动登录

### 验证 Session Memory
1. 问“今天天气怎么样”
2. 再问“刚才聊了什么” → Agent 能回忆之前的对话

### 验证用户画像
1. 聊几轮（“我预算8000”、“我喜欢轻薄本”）
2. 查看后端日志，应该有 `[UserProfile] 用户 xxx 画像更新`
3. 查数据库：`SELECT * FROM user_profile;`
4. 再问“给我推荐笔记本” → Agent 参考偏好推荐

### 验证 LLM 交互日志
1. 聊几轮后查看 `logs/llm-chat.log`
2. 能看到每次请求的完整 System Prompt（含用户画像 + 对话历史）和 LLM 响应

### 验证摘要压缩
1. 连续聊超过 12 轮
2. 后端日志应该有 `[Summary] Session xxx 摘要完成`
